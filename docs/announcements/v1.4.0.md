# Flow v1.4 -- Audio Fidelity, Distribution & Public Showcase

Flow is an interpreted, statically-typed language for music production. Composers write musical ideas as code -- inline note streams (`| C4 D4 E4 |`), chord literals, musical-context blocks for tempo / time signature / key / tuning, and a flow operator (`->`) for chaining transforms -- and the interpreter renders them to WAV and MIDI through a full audio pipeline. The goals are ergonomics first, genre-agnostic by design, and the easy cases fast; the non-goals are general-purpose computation and maximum runtime efficiency. Flow is for code-minded composers who want to write a symphony, a ragtime, an EDM track, or a death-metal riff in the same buffer.

v1.4 ships the audio-fidelity rewrite plus Flow's first formal distribution surface:

- Phase 28 -- per-voice polyphony (`voicePool 32`, steal-oldest allocation) and 5 locked articulation envelopes (staccato / legato / accent / marcato / tenuto), with multi-track MIDI export emitting one GM-mapped track per sequence name.
- Phase 29 -- sampled tonal instruments (piano, brass, sax, strings, flute, bell) via a 3 MB CC-BY 4.0 University-of-Iowa MIS bundle layered under the Phase 28 articulation envelope.
- Phase 30 -- self-contained `flow` Linux x64 binary (~38 MB, no .NET runtime required) + 11-subcommand CLI + `install.sh` + XDG config at `~/.config/flow/config.toml` + bidirectional MIDI <-> Flow round-trip.
- Phase 31 -- LSP polish (4 closed gaps, semantic tokens, scale linting) plus JetBrains plugin scaffolding.
- Phase 32 -- full Scala (`.scl`) microtonal tuning loader + `tuning t { ... }` musical-context block, with `.kbm` keyboard mapping and non-octave scales (Carlos Alpha, Bohlen-Pierce).
- Phase 33 -- SFZ orchestral sampler (`use "@sfz"` opt-in; 19-entry GM symbol dict; 14-opcode common-subset parser; 441-frame equal-power crossfade); blessed external library: VSCO Community CE 1.1.0.
- Phase 34 -- two curated showcase pieces rendered entirely from Flow source, paired to demonstrate Flow's genre-agnostic reach inside a single release.

Listen to the showcase. *In Five Voices* is a ~60 s pensive ABA piece in D minor for 5 VSCO-CE orchestral instruments (violin, cello, flute, horn, timpani), routed through the Phase 33 SFZ sampler. *Stride & Stomp* is a ~58 s upbeat ragtime in F major for solo piano on VSCO-CE's `UprightPiano.sfz`. Both render from one v1.4 install -- same interpreter, same SFZ pipeline, opposite moods.
