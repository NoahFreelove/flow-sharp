Flow Language plugin — direct download & manual install

This page is the direct-download fallback for installing the Flow Language plugin in JetBrains IDEs (IntelliJ IDEA, PyCharm, WebStorm, GoLand, etc.) while the listing is awaiting JetBrains Marketplace review, or if you prefer to install from a downloaded .zip.

Prefer the Marketplace once it is live. When the plugin is approved, install it the normal way: Settings → Plugins → Marketplace, search for “Flow Language”, and click Install. The Marketplace listing will be linked from the project README.

1. Download the plugin .zip

Download the signed flow-jetbrains-1.5.0.zip from the project's GitHub Releases page (attached to the v1.5.0 release):

Download from GitHub Releases (v1.5.0)

The artifact is flow-jetbrains-1.5.0.zip — the same plugin archive produced by ./gradlew buildPlugin under flow-jetbrains/build/distributions/. Do not unzip it; the IDE installs the .zip as-is.

2. Install from disk

  1. Open your JetBrains IDE (IntelliJ IDEA Community 2024.2 or later, i.e. build 242+; older builds refuse the plugin).
  2. Go to Settings/Preferences → Plugins.
  3. Click the gear icon (⚙) at the top of the Plugins pane → Install Plugin from Disk…
  4. Select the downloaded flow-jetbrains-1.5.0.zip.
  5. Restart the IDE when prompted.

3. Prerequisite: the flow binary

The plugin is a thin bridge: it starts the Flow language server by running flow lsp. You must have the flow binary available.

  • On PATH (recommended). Install the Flow CLI and run flow install (Phase 30), which drops flow into ~/.local/bin/. Confirm with: 
    flow version
  • Or via FLOW_LSP_PATH (fallback). If flow is not on PATH, set the FLOW_LSP_PATH environment variable to the binary's absolute path before launching the IDE: 
    export FLOW_LSP_PATH=/absolute/path/to/flow
idea .
    The plugin's FlowLanguageServerFactory reads FLOW_LSP_PATH first and falls back to flow on PATH.

4. Verify it works

Open any .flow file. LSP4IJ auto-starts the language server — look for an “LSP” indicator in the status bar, and try typing to see completions, hovers, signature help, and diagnostics (the same features as the VSCode extension).

Troubleshooting

  • “Incompatible build” on install — your IDE is older than build 242. Update to 2024.2 or later.
  • No completions / server never starts — the flow binary is not discoverable. Confirm flow version works in a terminal, or set FLOW_LSP_PATH as above and restart the IDE.
  • Missing LSP4IJ dependency — the plugin depends on LSP4IJ; the IDE will offer to install it automatically when you install this plugin.
