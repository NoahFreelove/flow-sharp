# Quick Task 260608-x94: iOS-6 Home Redesign for flow-site Summary

Rewrote the flowlang.dev `/` route as the authentic iOS-6 skeuomorphic marketing page — linen ground, brushed-aluminum toolbar, Aqua jelly buttons, inset code wells, leather audio rack, bottom tab bar — ported faithfully from the gitignored design handoff (`index.html` + `flow.css`), wiring the already-ported `highlightFlow` (prerender-time Flow syntax highlighting) and `tones` (Web-Audio Play buttons) helpers, with `+page.ts` collapsed to prerender-only and a `+layout.svelte` `isHome` guard suppressing the shared chrome on the home route only.

## What was done

### Task 1 — Rewrite `+page.svelte` as the iOS-6 home (commit `79106ac`, cleanup `ca97c5c`)
- Fully replaced the Phase-49 "Logic-Pro-wood" home draft with the iOS-6 design, wrapped in a single `<div class="ios6-page">`.
- **Markup** reproduces `index.html` L71-219 with route/URL substitutions: brushed-aluminum `.toolbar` (♪-glyph brand + 5-link segmented `.nav`), the `.layout` (hero `.plate` with 4 screws + reflection wordmark + blurb + 2 CTAs, the 3 `.ex` code wells, the "Why Flow" `.feat` trio, the "How it sounds" `.leather` rack with 3 `.player` rows, the `.footer`), and the bottom `.tabbar` with the verbatim inline SVG icons. All nav routes to `/`, `/docs`, `/playground`, `/showcase`; GitHub links to `https://github.com/noahfreelove/flow-sharp` (`target="_blank" rel="noopener"`).
- **Script** (Svelte 5 runes): imports `highlightFlow` + `playTone/playMelody/playChord`; defines the 3 hero snippets (`HELLO`/`SCALE`/`CADENCE`) **verbatim** from `index.html` and precomputes `hello`/`scale`/`cadence = highlightFlow(...)` at script init (pure → runs at prerender; the `{@html}` in markup just emits the precomputed strings). Hero Play handlers fire `playTone(440,0.9,'triangle')` / `playMelody(['C4'..'G4'],0.34)` / 3 chords 900ms apart. Leather rack drives a `playingIndex = $state(-1)` + a 14-entry `vu = $state<number[]>` reactive VU array; on Play it sets `playingIndex`, gets `dur` from `playMelody`, starts a ~90ms `setInterval` randomizing the 14 bar heights, and a `dur*1000` `setTimeout` that resets. Timers are guarded (`clearVuTimers()` first) so a second click never leaks an interval/timeout.
- **Style** ports both `flow.css` (337 lines) and the `index.html` inline landing `<style>`, component-scoped (Svelte auto-scope). The shared `body{ linen ground }` was converted to a `.ios6-page{ ... background-attachment:fixed; min-height:100dvh }` full-viewport wrapper (app.css keeps owning `<body>`). The `:root{ }` token block stays global. The `{@html}` highlighter output is NOT scoped, so its token classes are emitted as `:global(.flow-code .tk-*)`. No `[data-theme='dark']` rules (light-only).
- **Cleanup** (`ca97c5c`): dropped `.btn.dark`, `.plate.tight`, `.code-body` — ported from `flow.css` but with no markup consumer on this page; svelte-check flagged them as unused CSS selectors.

### Task 2 — prerender-only `+page.ts` + `isHome` chrome guard (commit `1304614`)
- `+page.ts` collapsed to exactly `export const prerender = true;` — the new home self-highlights in the component, so the old shiki `load()` / `HighlightedExample` / `highlightExample` plumbing is gone.
- `+layout.svelte`: added `const isHome = $derived(current === '/');` next to `current`; wrapped the shared `<header class="site-chrome">` and the mobile slide-down `<nav>` (`{#if !isHome}{#if mobileOpen}…{/if}{/if}`) so `/` renders only its own toolbar + tab bar. `{@render children()}`, the theme `$effect`, `NAV_ITEMS`, `mobileOpen`, `isActive`, and the entire `<style>` block are unchanged.
