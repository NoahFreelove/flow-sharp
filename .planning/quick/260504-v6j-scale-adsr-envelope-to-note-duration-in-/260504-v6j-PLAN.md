<objective>
Fix the short-note envelope bug at its root: `EnvelopeProcessor.GenerateADSRCurve` currently clamps decay to whatever's left after attack, then clamps release to whatever's left after that — which collapses release to ZERO frames for any note whose total length is shorter than attack+decay. The result is short notes (32nd notes from MIDI conversion, anything tagged staccato in BarRenderer) ending on a non-zero sample → audible click, no release tail, "thin/choked" character.

Purpose: Composers writing or importing real piano material (Chopin nocturne MIDI is the immediate test case) need short notes to render with proper shape — attack + brief decay + brief release — instead of attack + truncated-decay + cliff. This is an ergonomics-first fix: short notes are common in real music; they should sound musical, not broken.

Output: One file changed (EnvelopeProcessor.cs), one regression test added. All callers (Piano, Brass, Sax, Flute, Strings, Organ, Wavetable, Sax-breath, Piano-transient) automatically benefit because they all funnel through `GenerateEnvelopeCurve`. Drums and Bell are unaffected (they don't use the duration-tied ADSR path).
</objective>

    Replace the clamping logic (lines 135-144) with proportional scale-to-fit. Keep the loop bodies (attack/decay/sustain/release ramps) UNCHANGED — they already use their per-phase frame counts correctly.

    New logic:

    ```csharp
    int attackFrames = (int)(attackSec * envelope.SampleRate);
    int decayFrames = (int)(decaySec * envelope.SampleRate);
    int releaseFrames = (int)(releaseSec * envelope.SampleRate);

    // If attack + decay + release exceeds totalFrames, scale all three down
    // proportionally so the envelope shape is preserved (just compressed in time)
    // and release is guaranteed to remain > 0 for any totalFrames >= 3.
    int requestedAdr = attackFrames + decayFrames + releaseFrames;
    if (requestedAdr > totalFrames)
    {
        double scale = (double)totalFrames / requestedAdr;
        attackFrames = (int)(attackFrames * scale);
        decayFrames = (int)(decayFrames * scale);
        releaseFrames = (int)(releaseFrames * scale);

        // Floor-rounding can leave 1-3 frames unallocated; give them to release
        // so the envelope ends at exactly 0 on the final sample (no cliff).
        int leftover = totalFrames - (attackFrames + decayFrames + releaseFrames);
        releaseFrames += leftover;
    }
    // (No clamps needed in the else branch — sustain absorbs the remainder.)

    int sustainFrames = totalFrames - attackFrames - decayFrames - releaseFrames;
    ```

    For `totalFrames == 0` the early `requestedAdr > 0` branch produces scale=0 → all phase counts = 0, leftover = 0, sustain = 0, loops don't execute, returns the zero-length array allocated at line 70. No exception path needed.
