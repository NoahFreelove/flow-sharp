# Quick Task 260426-v5s: examples/long_demo.flow

## Goal

A single `.flow` script that generates a ~10-minute WAV (and a parallel MIDI) which audibly walks through Flow's modern syntax — one feature spotlight every ~10–20 seconds.

## Scope

- **File**: `examples/long_demo.flow` (new)
- **Output**: `examples/output/long_demo.wav` (~10 min) + `examples/output/long_demo.mid`
- **No code-changes** to `flow-lang/` — only uses the existing language as it stands today.

Piano main piece (single `renderSong … "piano"` over many sections):
1. `gain X { … }` context — soft pad intro
2. Plain note streams — ascending C-major scale
3. Inline dynamics — `pp p mp mf f ff` markers in a stream
4. `dynamics ff { … }` block context
5. `crescendo` transform
6. `decrescendo` transform
7. `swell` transform
8. Articulation — accent (`>`)
9. Articulation — staccato (`stacc`)
10. Articulation — tenuto (`ten`)
11. Articulation — marcato (`marc`)
12. Ghost notes — `(ghost X)`
13. Grace notes — `(grace X)`
14. `trill +2st`
15. `tremolo 4`
16. `transpose +7st` (before/after via `concat`)
17. `retrograde` (before/after)
18. `invert` (before/after)
19. `up 1` / `down 1` (octave shifts)
20. `humanize 0.25`
21. `vary 0.3 42` (seeded variation)
22. Tuplet bracket `{3:2 …}q` (triplets)
23. Tuplet bracket `{5:4 …}q` (quintuplets)
24. Roman numerals in key (`| I IV V vi |`)
25. `progression | I:2 vi IV V |` DSL
26. Flat literals (`Bb Eb Ab Db Gb`)
27. Sharp literals (`C# F# G# D#`)
28. `enharmonic` respelling in `key Dbmajor` (with a print line)

32. `timesig 3/4` waltz
33. `key Aminor` modal shift
34. `reverbTime 2.5 { … }` per-section hall reverb
35. Chord brackets (`| [C4 E4 G4]w … |`)

Synth gallery (separate `renderSong` calls glued to the main piece via `appendBuffers`):
36. Buffer effect chain — `reverb` → `lowpass` → `compress`
37. `strings` preset
38. `organ` preset
39. `bell` preset
40. `brass` preset
41. `sax` preset
42. `drums` preset (kick/snare/hat MIDI map)
43. `appendBuffers` — sequential timeline construction
44. `tempoRamp 100 → 50` ritardando outro
45. `fadeIn 1.0` / `fadeOut 3.0` bookends
46. Dual export: `writeWav` (audio) + `writeMidi` (notation)

Plus: string interpolation (`$"…"`) used throughout the print lines.
