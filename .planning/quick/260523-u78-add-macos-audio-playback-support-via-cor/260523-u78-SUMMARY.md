## Decisions Made

- **CoreAudio probe in `IsAvailable()` uses a harmless `AudioQueueDispose(IntPtr.Zero, true)` call** — passing a null pointer returns a non-zero `OSStatus`, but that's discarded. What we care about is that the native library resolves; `catch (DllNotFoundException) return false` covers the Linux case, and any other exception is treated as "framework loaded, weird transient — still counts as available."
- **Free-buffer queue uses a poll-with-50ms-timeout `_bufferAvailable.Wait(50, ct)` loop** — keeps cancellation responsive (composer's Ctrl-C / playback cancellation tokens fire within 50ms) without busy-spinning. Same shape as the PulseAudio backend's per-chunk cancellation check.
- **`mAudioDataByteSize` is patched via `Marshal.WriteInt32(bufferPtr, offset, byteSize)` at the struct's known field offset** rather than full struct-roundtrip (PtrToStructure → mutate → StructureToPtr). Both correct; the direct write is simpler and leaves untouched-fields untouched (avoids unintentionally rewriting the mAudioData pointer or the auto-managed `mUserData` / `mPacketDescription*` tail).
