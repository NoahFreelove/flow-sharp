<objective>
Fix docs spacing/structure across BOTH render targets (GitHub wiki + flow-site /docs).

The flow-site docs renderer wraps each wiki `.md` (compiled by mdsvex) in `<article class="docs-prose">`. Because `flow-site/src/app.css:1` does `@import 'tailwindcss'`, Tailwind v4 **Preflight** zeroes `ul/ol/p/blockquote` margins and removes list markers globally. The `.docs-prose` `<style>` block only styles `h1/h2/h3`, inline code, and `pre` — it has NO rules for `ul/ol/li/p/blockquote/table/hr/strong/em`, so every bullet on all 26 wiki pages renders squished and markerless regardless of blank lines in the markdown.

Separately, `wiki/Home.md` `## Key Features` is a ~40-item flat bullet list with inconsistent blank-line spacing.

Purpose: composers reading docs on flowlang.dev see properly formatted prose; the GitHub wiki Home page reads with structure.
Output: prose typography rules added under `.docs-prose` (fixes all 26 pages at once) + a restructured Home.md Key Features section.
</objective>
