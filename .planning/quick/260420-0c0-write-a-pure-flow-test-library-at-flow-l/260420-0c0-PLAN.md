CRITICAL FINDINGS (grep-verified against flow-lang/StandardLibrary/BuiltInFunctions.cs):
- `not` is NOT registered as a built-in. The library MUST implement its own `not` helper as a `proc`,

- The array length primitive is `len` (line 348–349 of BuiltInFunctions.cs). `length` does NOT exist.
- Comparison primitives are `lt`, `gt`, `lte`, `gte` (lines 255–272). Use these exact names.
- `reduce` signature is `(reduce arr initial callback)` with callback `(fn Void acc, Void x => ...)`.

<style_rules>
<!-- From user memory + flow-lang/audio.flow idiom -->
- Functional S-expression only. Every expression is `(func arg1 arg2 ...)`. No infix.
  - WRONG: `if a == b` or `a + b`
  - RIGHT: `(equals a b)`, `(add a b)`
- Follow flow-lang/audio.flow `proc` style: declare locals, end with the expression that is the return value.
- Lambda syntax: `fn Int n => (expr)` or `fn Int a, Int b => (expr)`.
- Comments use `Note: ...` (flow convention) — NOT `//`.
- String concat: `(concat s1 s2)` — repeat for >2 pieces, e.g. `(concat (concat "[" label) "]")`.
</style_rules>

Create `flow-lang/test.flow` as a pure-Flow module. MUST start with:
```
Note: Pure-Flow Test Library
Note: Assertions print PASS/FAIL and return Bool so results can be reduced via summary.

use "@std"
use "@collections"
```

Then implement each proc below. NO `internal proc` declarations anywhere in this file.

**Helper procs (private-by-convention, but Flow has no access modifier — just define at top):**

1. `proc notBool(Bool: b)` — returns `(if b false true)`. Needed because `not` is not a registered primitive (see context).
2. `proc printResult(Bool: passed, String: label)` — prints `"PASS: <label>"` or `"FAIL: <label>"` using `(concat "PASS: " label)` / `(concat "FAIL: " label)` and `(if passed ... ...)`. Returns `passed`.

**Core assertions (all return `Bool` so results can be collected):**

3. `proc assertTrue(Bool: cond, String: label)` — `(printResult cond label)`
4. `proc assertFalse(Bool: cond, String: label)` — `(printResult (notBool cond) label)`
5. `proc assertEqual(Void: a, Void: b, String: label)` — `(printResult (equals a b) label)`
6. `proc assertNotEqual(Void: a, Void: b, String: label)` — `(printResult (notBool (equals a b)) label)`
7. `proc assertLess(Void: a, Void: b, String: label)` — `(printResult (lt a b) label)`
8. `proc assertGreater(Void: a, Void: b, String: label)` — `(printResult (gt a b) label)`
9. `proc assertLessOrEqual(Void: a, Void: b, String: label)` — `(printResult (lte a b) label)`
10. `proc assertGreaterOrEqual(Void: a, Void: b, String: label)` — `(printResult (gte a b) label)`
11. `proc assertApproxEqual(Double: a, Double: b, Double: epsilon, String: label)` — compute `(abs (sub a b))`, compare `(lte diff epsilon)`, call `(printResult passed label)`.

**Runner + summary:**

12. `proc test(String: name, Function: thunk)` — prints `(concat "=== " name)` then calls `(thunk)` which must return `Bool`, then calls `(printResult result name)` and returns the result. This wraps a labeled test block whose body is a zero-arg lambda returning a single Bool.
13. `proc summary(Bool[]: results)` — tally via reduce:
    - `Int total = (len results)`
    - `Int passed = (reduce results 0 (fn Int acc, Bool r => (if r (add acc 1) acc)))`
    - `Int failed = (sub total passed)`
    - Print three lines: `"=== SUMMARY ==="`, `(concat "Passed: " (str passed))`, `(concat "Failed: " (str failed))`, `(concat "Total:  " (str total))`
    - Return `(equals failed 0)` so callers can branch on "all green".

**Style checklist — verify before marking done:**
- [ ] Zero occurrences of `internal proc` in file
- [ ] Zero infix operators (no `==`, `!=`, `+`, `-`, `<`, `>`, `&&`, `||`). Every expression is parenthesized S-expr.
- [ ] Comments use `Note:` not `//`
- [ ] Every `proc` ends with `end proc`
- [ ] Return value of each assertion is `Bool` (the implicit last expression)
- [ ] `summary` uses `len` (not `length`) and `reduce` — no manual counters / mutable globals

Follow the `proc` idiom exactly as in flow-lang/audio.flow's `secondsToFrames`, `isMono`, `buffersCompatible` — declare typed locals, end with the bare return expression.
