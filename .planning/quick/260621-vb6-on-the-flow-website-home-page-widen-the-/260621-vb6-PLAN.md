# Quick Task: Widen the home-page hero on desktop

## Description

On the flowlang.dev home page (`flow-site/src/routes/+page.svelte`), the hero
sits inside the shared `.layout` content column, which caps the whole page at
`max-width: 1080px`. The composer wants the hero noticeably wider on desktop.

## Decisions (from clarification)

- **Scope:** widen the whole page column (`.layout`), not a hero-only breakout —
  hero AND the "Why Flow" / feature sections widen together, staying aligned.
- **Target width:** ~1440px (a fair bit wider, +360px).
- **Desktop-only is automatic:** `max-width` only binds above ~1080px; narrower
  viewports already fill available width minus the `clamp()` side padding, so no
  new media query is needed.

## Task

Change `.layout { max-width: 1080px }` → `1440px` in
`flow-site/src/routes/+page.svelte`.

- **files:** `flow-site/src/routes/+page.svelte`
- **action:** bump the single `.layout` `max-width` declaration from `1080px`
  to `1440px`.
- **verify:** only one `1080` reference existed (the `.layout` rule); both card
  grids (`.cards3`, `.feat`) use `repeat(3, minmax(0, 1fr))` so they scale
  fluidly; no test asserts on the old value. Run `pnpm -C flow-site build` to
  confirm the build stays green.
- **done:** `.layout` reads `max-width: 1440px`; build passes.
