Build the formant vocal synthesis engine -- the core DSP classes that generate vowel and consonant audio from formant frequency tables.

Purpose: This is the audio engine behind `sing()`. It produces recognizable vowel sounds (Kraftwerk-style formant synthesis) by filtering a buzz source through parallel bandpass filters tuned to vowel formant frequencies. Consonant approximations enable syllable combinations like "na", "ta", "sa".

Output: Three C# classes in `flow-lang/StandardLibrary/Audio/Vocalization/` that can synthesize any of 5 vowels and 3 consonants into AudioBuffer/float[] data.

**FormantSynthesizer.cs** (namespace `FlowLang.StandardLibrary.Audio.Vocalization`):

Create a static class `FormantSynthesizer` with:

1. `public static AudioBuffer SynthesizeVowel(string vowel, double frequencyHz, double durationSeconds, int sampleRate = 44100)`:

   - Calculate `numSamples = (int)(durationSeconds * sampleRate)`.
   - Create `float[] buzzSamples = new float[numSamples]`.
   - Generate buzz source: `SynthUtils.GenerateSaw(buzzSamples, frequencyHz, 0.8, sampleRate)`.
   - Apply spectral tilt: `SynthUtils.OnePoleLP(buzzSamples, frequencyHz * 4, sampleRate)` to simulate glottal source roll-off.
   - Create a mono `AudioBuffer buzzBuffer` from `buzzSamples` (new AudioBuffer with frames=numSamples, channels=1, sampleRate; then `Array.Copy(buzzSamples, buzzBuffer.Data, numSamples)`).
   - Get formants: `var formants = FormantData.GetFormants(vowel)`.
   - Create result `AudioBuffer` (mono, same size).
   - For each formant:
     - Compute `lowHz = formant.Frequency - formant.Bandwidth / 2f` and `highHz = formant.Frequency + formant.Bandwidth / 2f`.
     - Clamp: `lowHz = Math.Max(lowHz, 20f)`, `highHz = Math.Min(highHz, sampleRate / 2f - 1f)`.
     - Skip if `highHz <= lowHz`.
     - Call `Filter.Bandpass(buzzBuffer, lowHz, highHz)`.
     - Convert amplitude: `float gain = FormantData.DbToLinear(formant.AmplitudeDb)`.
     - Add to result: `for (int i = 0; i < result.Data.Length && i < filtered.Data.Length; i++) result.Data[i] += filtered.Data[i] * gain;`
   - Apply ADSR envelope: attack=0.02, decay=0.05, sustain=0.8, release=0.05.
   - Apply master gain of 0.3f to prevent clipping (multiply all samples by 0.3f).
   - Return result.

2. `public static AudioBuffer SynthesizeSyllable(string phoneme, double frequencyHz, double durationSeconds, int sampleRate = 44100)`:

   - If phoneme length == 1 or phoneme starts with a vowel sound, delegate to `SynthesizeVowel`.
   - If phoneme length >= 2 and first char is a recognized consonant ('s', 't', 'n'):
     - Extract consonant = phoneme[0..1] (first char as string).
     - Map remaining chars to vowel: "a"->"ah", "e"->"eh", "i"->"ee", "o"->"oh", "u"->"oo". If no mapping found, treat entire string as vowel phoneme name.
     - Generate consonant onset via `ConsonantSynthesizer.Generate(consonant, frequencyHz, sampleRate)`.
     - Generate vowel body via `SynthesizeVowel(vowelName, frequencyHz, durationSeconds, sampleRate)`.
     - Crossfade: overlap last 2ms of consonant with first 2ms of vowel (linear crossfade to avoid clicks per research pitfall 6).
     - Concatenate: consonant (minus overlap) + crossfade region + vowel (minus overlap).
     - Return combined AudioBuffer.
   - Otherwise delegate to `SynthesizeVowel(phoneme, frequencyHz, durationSeconds, sampleRate)`.

**ConsonantSynthesizer.cs** (namespace `FlowLang.StandardLibrary.Audio.Vocalization`):

Create a static class `ConsonantSynthesizer` with:

1. `public static float[] Generate(string consonant, double pitchHz, int sampleRate)`:
   Returns a float[] containing the consonant onset samples. Switch on consonant:
   - `"s"` -> call `GenerateFricative(sampleRate)`
   - `"t"` -> call `GeneratePlosive(sampleRate)`
   - `"n"` -> call `GenerateNasal(pitchHz, sampleRate)`
   - default -> return `Array.Empty<float>()`

2. `private static float[] GenerateFricative(int sampleRate)`:
   - Duration: 80ms. Calculate `int samples = sampleRate * 80 / 1000`.
   - Create `float[] buffer = new float[samples]`.
   - Fill with white noise: `SynthUtils.GenerateWhiteNoise(buffer, 0.3)`.
   - Apply highpass filtering: create a temporary mono AudioBuffer from the float[], apply `Filter.Highpass(tempBuf, 4000f)`, copy result data back.
   - Apply a fast fade-in (2ms) and fade-out (10ms) to avoid clicks:
     - Fade-in: first `sampleRate * 2 / 1000` samples linearly ramp from 0 to 1.
     - Fade-out: last `sampleRate * 10 / 1000` samples linearly ramp from 1 to 0.
   - Return buffer.

3. `private static float[] GeneratePlosive(int sampleRate)`:
   - Duration: 10ms. Calculate `int samples = sampleRate * 10 / 1000`.
   - Create `float[] buffer = new float[samples]`.
   - Fill with white noise: `SynthUtils.GenerateWhiteNoise(buffer, 0.5)`.
   - Apply sharp attack envelope: exponential decay from 1.0 to 0.0 over the duration.
     `buffer[i] *= (float)Math.Exp(-5.0 * i / samples)` for each sample.
   - Return buffer.

4. `private static float[] GenerateNasal(double pitchHz, int sampleRate)`:
   - Duration: 40ms. Calculate `int samples = sampleRate * 40 / 1000`.
   - Create `float[] buffer = new float[samples]`.
   - Generate buzz at pitch: `SynthUtils.GenerateSaw(buffer, pitchHz, 0.4, sampleRate)`.
   - Apply heavy lowpass at 500 Hz to keep only the low nasal resonance: `SynthUtils.OnePoleLP(buffer, 500, sampleRate)`.
   - Apply fade-in (2ms) and fade-out (5ms) to avoid clicks.
   - Return buffer.

5. `public static bool IsConsonant(char c)`:
   Return `c == 's' || c == 't' || c == 'n'`.

All methods are static. File-scoped namespace. Use `using FlowLang.StandardLibrary.Audio.Synthesizers;` for SynthUtils and `using FlowLang.StandardLibrary.Audio.DSP;` for Filter.
