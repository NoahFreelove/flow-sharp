**TtsHook.cs** (namespace `FlowLang.StandardLibrary.Audio.Vocalization`):

Create a static class `TtsHook` with:

1. `private static string _ttsCommand = "espeak-ng --stdout";` (per D-08)

2. `public static void SetCommand(string command)` -- sets `_ttsCommand`. Throw `ArgumentException` if command is null or whitespace.

3. `public static string GetCommand()` -- returns current `_ttsCommand`.

4. `public static AudioBuffer RunTts(string text)`:
   - Split `_ttsCommand` on first space: `var parts = _ttsCommand.Split(' ', 2);` 
   - `string executable = parts[0];`
   - `string baseArgs = parts.Length > 1 ? parts[1] : "";`
   - Create `Process` with `StartInfo`:
     - `FileName = executable`
     - `Arguments = $"{baseArgs} \"{text}\""` (quote the text to handle spaces)
     - `RedirectStandardOutput = true`
     - `RedirectStandardError = true`
     - `UseShellExecute = false`
     - `CreateNoWindow = true`
   - Wrap in try/catch:
     - `process.Start()`
     - Read stdout into `MemoryStream`: `process.StandardOutput.BaseStream.CopyTo(memStream)`
     - `process.WaitForExit(30000)` (30-second timeout per research pitfall 3)
     - If timeout (returns false): kill process, throw `InvalidOperationException("TTS command timed out after 30 seconds")`
     - If `process.ExitCode != 0`: read stderr, throw `InvalidOperationException($"TTS command failed (exit {process.ExitCode}): {stderr}")`
     - Parse WAV from `memStream`: call `LoadWavFromStream(memStream)` (see below).
   - Catch `System.ComponentModel.Win32Exception`: throw `InvalidOperationException($"TTS command not found: '{executable}'. Install it or change with setTtsCommand()")`

5. `private static AudioBuffer LoadWavFromStream(MemoryStream stream)`:
   - Duplicate the WAV parsing logic from `FileIO.LoadWavInternal` but reading from the MemoryStream via a BinaryReader instead of a FileStream.
   - `stream.Position = 0;`
   - `using var reader = new BinaryReader(stream, System.Text.Encoding.UTF8, leaveOpen: true);`
   - Read RIFF header, parse fmt and data chunks, create AudioBuffer -- same logic as FileIO.LoadWavInternal.
   - Resample to 44100 if needed (call the same pattern: if sampleRate != 44100, resample using linear interpolation).
   - If stream is empty or invalid WAV, throw `InvalidOperationException("TTS command produced invalid or empty WAV output")`.

Use `using System.Diagnostics;` for Process and `using System.IO;` for MemoryStream.

**VocalizationFunctions.cs** (namespace `FlowLang.StandardLibrary.Audio.Vocalization`):

Create a static class `VocalizationFunctions` following the `EffectsFunctions.Register` pattern:

1. `public static void Register(InternalFunctionRegistry registry)`:

   Register three functions:

   a) `sing(String, Note, Double) -> Buffer` (per D-05):
   ```
   var singSignature = new FunctionSignature("sing",
       [StringType.Instance, NoteType.Instance, DoubleType.Instance]);
   registry.Register("sing", singSignature, Sing);
   ```

   b) `tts(String) -> Buffer` (per D-06):
   ```
   var ttsSignature = new FunctionSignature("tts", [StringType.Instance]);
   registry.Register("tts", ttsSignature, Tts);
   ```

   c) `setTtsCommand(String) -> Void` (per D-08):
   ```
   var setTtsSig = new FunctionSignature("setTtsCommand", [StringType.Instance]);
   registry.Register("setTtsCommand", setTtsSig, SetTtsCommand);
   ```

2. `private static Value Sing(IReadOnlyList<Value> args)`:
   - Extract phoneme: `string phoneme = args[0].As<string>();`
   - Extract note as string: `string noteStr = (string)args[1].Data!;`
   - Parse note string to frequency: Parse noteStr to extract noteName (char), octave (int), alteration (int):
     - `char noteName = noteStr[0];`
     - `int alteration = 0; int idx = 1;`
     - If `idx < noteStr.Length && noteStr[idx] == '#'` then `alteration = 1; idx++;`
     - Else if `idx < noteStr.Length && noteStr[idx] == 'b'` then `alteration = -1; idx++;`
     - `int octave = int.Parse(noteStr[idx..]);`
     - `double frequencyHz = PitchConversion.NoteToFrequency(noteName, octave, alteration);`
   - Extract duration: `double duration = args[2].As<double>();`
   - Call `FormantSynthesizer.SynthesizeSyllable(phoneme, frequencyHz, duration)`.
   - Return `Value.Buffer(result)`.

3. `private static Value Tts(IReadOnlyList<Value> args)`:
   - Extract text: `string text = args[0].As<string>();`
   - Call `TtsHook.RunTts(text)`.
   - Return `Value.Buffer(result)`.

4. `private static Value SetTtsCommand(IReadOnlyList<Value> args)`:
   - Extract command: `string command = args[0].As<string>();`
   - Call `TtsHook.SetCommand(command)`.
   - Return `Value.Void()`.
