Body computes repo root by walking up from `${BASH_SOURCE[0]}` until `flow-sharp.sln` is found (mirrors the FindRepoRoot pattern used in xUnit fixtures). Then:

```
mkdir -p "$OUT_DIR"
grep -rn "Math\.Clamp.*args\[" "$REPO_ROOT/flow-lang/StandardLibrary/" > "$OUT_DIR/input-clamps.txt" || true
grep -rn "Math\.Clamp\|Math\.Min.*Math\.Max" "$REPO_ROOT/flow-lang/StandardLibrary/" > "$OUT_DIR/all-clamps.txt" || true

grep -rnE "(fallback|charitable|else.*return.*input)" "$REPO_ROOT/flow-lang/StandardLibrary/" > "$OUT_DIR/charitable-sites.txt" || true
```

(The `|| true` after each grep prevents `set -e` from exiting on zero matches — RESEARCH §Pitfall 4 notes that empty greps are data, not failure.)

Final summary uses `wc -l` to print line counts and writes them to `$OUT_DIR/summary.txt`:
```
input-clamps.txt:    N lines
all-clamps.txt:      N lines
advisory-sites.txt:  N lines
charitable-sites.txt: N lines
```
Echo summary to stdout. Exit 0.

Both scripts should be runnable from any cwd — resolve `$REPO_ROOT` first.
