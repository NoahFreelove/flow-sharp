<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `///` example source → in-process FlowEngine | Doc examples are `.flow` source executed during generation. |
| `--out` CLI arg → filesystem | User-supplied output dir could attempt path traversal. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41-03-DOS | Denial of Service | DocExampleRunner running `.flow` examples | mitigate | Reuse the Phase 35 hermetic `TestRunner` state reset between examples; examples are tiny; the Phase 38 30 s wall-clock cap pattern is available if a runaway example appears (recommend a per-example time budget). |
| T-41-03-V12 | Tampering (path traversal) | `flow doc --out` | mitigate | Normalize `--out` with `Path.GetFullPath`; confine all writes under the resolved dir; default `docs/reference`. `FlowDocGenTests` asserts traversal-shaped args don't escape. |
| T-41-03-V5 | Input Validation | DocCollector lexing untrusted-shaped `.flow` | mitigate | Goes through the charitable lexer/parser (errors accumulate, never crash). Harvest bounded by `TopDirectoryOnly` + name pattern (T-35-10 precedent). |
| T-41-03-SC | Tampering | npm/pip/cargo installs | accept | No new package installs (pure C# tooling over existing FlowEngine/BuiltInDocs). |
</threat_model>
