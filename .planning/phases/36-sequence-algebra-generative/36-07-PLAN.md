**Algorithm (textbook L-system):**
```
current = [axiom]
for i in 0..iterations:
    next = []
    for sym in current:
        if rules.has(sym): next.extend(rules[sym])
        else: next.append(sym)  // terminal — passes through unchanged
    current = next
return current
```

**Charitable interpretation (Pitfall 2):**
- Empty rules dict → axiom passes through unchanged for all iterations + WarnOnce
- Axiom not a Symbol → WarnOnce + return empty
- Iterations < 0 → clamp to 0 + WarnOnce
- Iterations > 20 → clamp to 20 + WarnOnce (DoS guard per RESEARCH §Security Domain — exponential growth caps at ~10^7 symbols)
