**StyleRegistry (StandardLibrary/Improv/StyleRegistry.cs):**
```
public static class StyleRegistry
{
    public static void LoadAtEngineInit(FlowEngine engine, ExecutionContext context)
    {
        // 1. Shipped packs first (load order locked per Pitfall 8)
        string shippedDir = Path.Combine(engine.StdLibRoot, "improv", "styles");
        LoadDir(engine, context, shippedDir, source: "shipped");

        // 2. User packs second (overrides win)
        string userDir = Path.Combine(
            Environment.GetFolderPath(Environment.SpecialFolder.UserProfile),
            ".config", "flow", "styles");
        LoadDir(engine, context, userDir, source: "user");
    }

    private static void LoadDir(FlowEngine engine, ExecutionContext context, string dir, string source)
    {
        if (!Directory.Exists(dir)) return;
        foreach (var file in Directory.GetFiles(dir, "*.flow"))
        {
            try { engine.Execute(File.ReadAllText(file)); }
            catch (Exception ex)
            {
                RenderingDiagnostics.WarnOnce($"styleRegistry:loadFail:{file}",
                    $"[improv] failed to load style pack '{file}': {ex.Message}");
            }
        }
    }
}
```

The actual `(registerStyle #name pack)` builtin call mutates `context.StyleRegistry`. Pack collision: WarnOnce with sentinel `improv:override:{name}` per Pitfall 8.

**Jam algorithm (RESEARCH §Pattern 8):**
```
jam(over, style, length, keyOverride, seed, order):
    1. Look up rule pack from StyleRegistry[style] (charitable fallback to #jazz if unknown — WarnOnce)
    2. Push synthetic MusicalContext frame if keyOverride != null
    3. Resolve PRNG: seed.HasValue ? new Random(seed) : context.PrngRegistry.GetRandom(callSite, "jam")
    4. Resolve current key from MusicalContext (active key context after step 2's push)
    5. For each bar in [0..length):
        a. Pick chord for this bar via over.Bars[bar % over.Bars.Count]
        b. Extract chord tones from chord (ChordParser.Parse → ChordData.Notes)
        c. Extract scale tones for current key from ScaleDatabase
        d. For each beat position in the rhythmic_template:
           i. Determine beat strength (strong / weak / syncopated) from beat position + timesig
           ii. Read chord_tone/scale_tone/chromatic_passing weights from rule pack
           iii. Weighted-sample category via rng.NextDouble()
           iv. Within category, pick specific note via interval_transitions weights relative to previous note
           v. Apply articulation per articulation_distribution
        e. Build BarData with these notes
    6. Pop frame
    7. Return Sequence(bars)
```

**Charitable interpretation:**
- Empty `over` → return empty Sequence + WarnOnce
- Unknown style → fall back to #jazz + WarnOnce
- length <= 0 → return empty + WarnOnce
- order outside [1, 3] → clamp + WarnOnce (matches Markov order clamp)
- Rule pack missing required field → use built-in default for that field + WarnOnce (per-field-once)
- Style + key musical incompatibility (e.g., #blues + chromatic key — detection heuristic: scale_tone_weight is non-zero but the active key has > 4 non-scale tones in the chord progression) → WarnOnce `[jam] style '#blues' + key '<key>' may produce unexpected harmonic flavor`
