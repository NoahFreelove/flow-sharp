**Builtin surface (StandardLibrary/Generative/MarkovFunctions.cs):**
- `markovTrain(Sequence corpus, Int order) → MarkovModel` — Phase 36 D-36-07 feature default "pitch"
- `markovTrain(Sequence corpus, Int order, features=Symbol|Tuple<Symbol,...>) → MarkovModel` — named-arg surface
- `markovGenerate(MarkovModel model, Int length, Int seed) → Sequence` — explicit seed
- `markovGenerate(MarkovModel model, Int length) → Sequence` — unseeded, PrngRegistry-routed
- `markov(Sequence corpus, Int order, Int length, Int seed) → Sequence` — one-shot wrapper composing train+generate
- `markov(Sequence corpus, Int order, Int length) → Sequence` — unseeded one-shot
- `markovEqual(MarkovModel a, MarkovModel b) → Bool` — structural compare via Order + FeatureMode + Transitions

Use `RegisterContextDependent(registry, context)` shape because unseeded paths need `context.PrngRegistry`.

ParameterNames per Plan 36-02:
- markovTrain: `["corpus", "order"]` or `["corpus", "order", "features"]`
- markovGenerate (seeded): `["model", "length", "seed"]`
- markovGenerate (unseeded): `["model", "length"]`
- markov (seeded one-shot): `["corpus", "order", "length", "seed"]`
- markov (unseeded one-shot): `["corpus", "order", "length"]`
- markovEqual: `["a", "b"]`

**Algorithm (textbook Markov):** Train builds `Transitions: prefix → [next-state, weight]` from corpus by sliding `order`-sized window over corpus notes. Generate seeds with first window from corpus, then samples next state by cumulative-weight roulette using rng.NextDouble().

**Feature extraction (D-36-07):**
- `features=#pitch` (default): state is the MIDI pitch int
- `features=<<#pitch, #duration>>`: state is `(pitch, duration_quarters_int)` encoded as a stable int — pack pitch into low 12 bits + duration into high 20 bits (or use Tuple<int,int> as the ImmutableArray<int> element — design choice; document in SUMMARY)
