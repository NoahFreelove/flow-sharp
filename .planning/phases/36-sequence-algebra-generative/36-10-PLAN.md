**ExpressionEvaluator section-call dispatch (NEW method EvaluateSectionCall):**
```
private Value EvaluateSectionCall(SectionCallElement call)
{
    // 1. Evaluate all positional args + named args to Values
    var positionalValues = call.PositionalArgs.Select(EvaluateExpression).ToList();
    var namedValues = call.NamedArgs?.ToDictionary(kvp => kvp.Key, kvp => EvaluateExpression(kvp.Value));

    // 2. Fold named args into positional slots per param order (D-36-15 default-value support)
    // For each param slot, if positional arg present use it; else if named arg present use it; else if DefaultValues[i] non-null, evaluate; else MISSING
    // ... build finalArgs: List<Value> ...

    // 3. Resolve overload via OverloadResolver.ResolveSection(name, finalArgs, _context)
    var section = _context.OverloadResolver.ResolveSection(call.Name, finalArgs, _context);
    if (section == null) return Value.Void();  // diagnostic already emitted

    // 4. Pattern-match args against section.Parameters; bind variables in a synthetic frame
    var (_, bindings, _) = PatternMatcher.TryMatchAll(section.Parameters, finalArgs, _context);

    // 5. Push frame; declare bindings; execute body; pop frame
    _context.PushFrame();
    try
    {
        foreach (var (name, value) in bindings)
            _context.CurrentFrame.DeclareVariable(name, value);
        return ExecuteSectionBody(section.Body);  // existing executor — composes with the new frame
    }
    finally
    {
        _context.PopFrame();
    }
}
```
