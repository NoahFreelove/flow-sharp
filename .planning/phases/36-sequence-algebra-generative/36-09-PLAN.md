**Lorenz algorithm (forward-Euler integration, ~15 LOC per RESEARCH §Pattern 5):**
```
double x = 1.0, y = 0.0, z = 0.0  // initial conditions derived from seed via Random
var rng = new Random(seed);
x += (rng.NextDouble() - 0.5) * 0.001;  // small perturbation for non-trivial trajectory
double dt = 0.01;
var warmup = 100;  // discard first 100 iterations (chaotic transient)
var result = new double[length];
for (int i = 0; i < warmup; i++) { /* iterate dx/dy/dz */ }
for (int i = 0; i < length; i++) {
    double dx = sigma * (y - x);
    double dy = x * (rho - z) - y;
    double dz = x * y - beta * z;
    x += dx * dt;
    y += dy * dt;
    z += dz * dt;
    result[i] = x;  // return x-axis (composer can pick y or z via future kwarg)
}
return result;
```

Default canonical params (RESEARCH-validated): σ=10, ρ=28, β=8/3 — the butterfly.

**Logistic algorithm:**
```
double x = rng.NextDouble();  // initial in (0, 1)
var warmup = 100;
for (int i = 0; i < warmup; i++) x = r * x * (1 - x);
var result = new double[length];
for (int i = 0; i < length; i++) {
    x = r * x * (1 - x);
    result[i] = x;
}
return result;
```

**quantizeToScale algorithm:**
```
// series values are unbounded for Lorenz, in [0,1] for logistic
// Normalize: find min/max of series, scale to [0, scaleNotes.Length-1]
double min = series.Min(), max = series.Max();
var quantized = new List<MusicalNoteData>();
double range = (max - min) > 1e-9 ? (max - min) : 1.0;  // avoid /0
foreach (var v in series) {
    double normalized = (v - min) / range;  // [0, 1]
    int idx = Math.Clamp((int)(normalized * scaleNotes.Length), 0, scaleNotes.Length - 1);
    var note = scaleNotes[idx];
    quantized.Add(new MusicalNoteData(note, duration: q));  // quarter notes
}
return new SequenceData(bars: groupQuartersIntoBars(quantized, timesig));
```

**Charitable interpretation (Pitfall 2):**
- Lorenz: σ < 0 OR ρ <= 0 OR β <= 0 → use canonical defaults (σ=10, ρ=28, β=8/3) + WarnOnce
- Logistic: r outside [0, 4] → clamp + WarnOnce (r > 4 produces escape from [0,1] and NaN); r in [0, 3] is non-chaotic (settles to fixed point) — composer's intent, no advisory
- length <= 0 → empty + WarnOnce
- length > 100_000 → clamp + WarnOnce (DoS guard)
