**1D elementary CA algorithm (RESEARCH §Pattern 4):**
```
initial = new bool[width]  // all false
initial[width / 2] = true  // single-1-center default
grid = [initial]
for step in 0..steps-1:
    next = new bool[width]
    for i in 0..width-1:
        left = grid[step][(i-1+width) % width]  // wrap-around
        center = grid[step][i]
        right = grid[step][(i+1) % width]
        pattern = (left ? 4 : 0) | (center ? 2 : 0) | (right ? 1 : 0)  // 0-7
        next[i] = (rule >> pattern) & 1 == 1
    grid.append(next)
return grid
```

**Grid → Sequence mapping (1D):** each row becomes a Bar; each true cell becomes a note at a fixed pitch (e.g., C4) with eighth-note duration; false cells become rests. Concrete mapping: column 0 → onset position 0 of bar; column N → onset position N. Pitch base: C4. Note duration: 1/width of a whole note (so a width-16 grid maps to sixteenth-notes evenly filling 1 bar). Document the mapping in SUMMARY — researcher discretion (D-36-08).

**2D Game of Life algorithm:**
```
initial = new bool[height][width]
rng = new Random(seed)  // EXPLICIT — composer always passes seed per REQ
for r in 0..height-1:
    for c in 0..width-1:
        initial[r][c] = rng.NextDouble() < 0.30  // 30% density
grid = [initial]
for step in 0..steps-1:
    next = new bool[height][width]
    for r in 0..height-1:
        for c in 0..width-1:
            neighbors = count_alive_neighbors(grid[step], r, c)  // Moore neighborhood, wrap-around
            alive = grid[step][r][c]
            next[r][c] = (alive ? (neighbors == 2 || neighbors == 3) : neighbors == 3)
    grid.append(next)
return grid
```

**Grid → Array[Sequence] mapping (2D):** each row across all steps → one Sequence; row index → pitch (Y-axis = pitch); column index → time position in bar; true cell → note, false → rest. Result is an `Array[Sequence]` of length `height`. Document.

**Charitable interpretation (Pitfall 2):**
- rule outside [0, 255] → wrap via `(rule & 0xFF)` + WarnOnce
- width / height / steps <= 0 → return empty + WarnOnce
- width or height > 1024 OR steps > 1024 → clamp + WarnOnce (DoS guard)

**No PrngRegistry routing for these primitives** — REQ signatures REQUIRE the seed argument explicitly. The composer-passed seed flows directly to `new Random(seed)`. PRNG-gate test scope: 2D life uses `new Random(seed)` exactly once (initial fill); 1D cellular has no PRNG (single-1-center default). PrngRegistryNewRandomGateTests should be relaxed (or amended) to allow up to 2 `new Random(` in CellularFunctions.cs (one per life initial fill + one if we add an unseeded overload later). For v1.5 ship the gate to allow up to 1 (the life initial fill only).
