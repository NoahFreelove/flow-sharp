    private AudioBuffer? _capturedBuffer;

    /// When true, play()/loop() store the buffer instead of playing through PulseAudio.
    /// Used by background FlowEngine instances during live reload.
    /// </summary>

    Create `flow-interpreter/LiveReloadManager.cs` (per D-13, D-14). This class encapsulates:

    **Fields:**
    - `_filePath` (string), `_deviceName` (string?)
    - `_currentBuffer` (float[]?) -- currently playing audio data (use Volatile.Read/Write)
    - `_pendingBuffer` (float[]?) -- buffer waiting to swap in at next bar boundary (use Interlocked.Exchange)
    - `_pendingMusicalContext` (MusicalContext?) -- tempo/timesig from the pending version
    - `_currentTempo` (double, default 120.0) -- from currently-playing version per D-03
    - `_currentBeatsPerBar` (int, default 4) -- from currently-playing version per D-03
    - `_currentSampleRate` (int, default 44100), `_currentChannels` (int, default 2)
    - `_cts` (CancellationTokenSource?) -- for stopping everything
    - `_playbackTask` (Task?) -- the streaming loop task
    - `_watcher` (FileSystemWatcher?) -- file change watcher
    - `_lastChangeTime` (DateTime) -- debounce tracking

    **Constructor:** Takes `filePath` and `deviceName`.

    **`Run()` method** -- Main entry point (called from Program.cs):
    1. Perform initial execution: create a `FlowEngine` with `CaptureMode = true`, execute the script, extract the rendered buffer via `engine.AudioManager.GetCapturedBuffer()`. If no buffer captured, also check `engine.ExecuteExpression()` for a Buffer return value. Extract musical context via `engine.Context.GetMusicalContext()`. Store tempo, beatsPerBar, buffer data.
    2. Set up `FileSystemWatcher` on the file (per D-01, reuse pattern from existing `RunWithWatch`): watch directory for fileName changes, 500ms debounce via DateTime comparison. On change, call `TriggerBackgroundRender()`.
    3. Start the streaming playback loop via `Task.Run(() => StreamingLoop(ct))`.
    4. Set up Ctrl+C handler: first press stops playback (`_cts.Cancel()`), second press exits. Print "Watching {fileName} for changes... (Ctrl+C to stop)".
    5. Block on `_playbackTask` (or a manual reset event) until cancellation.
    6. Dispose watcher, engine resources.

    **`StreamingLoop(CancellationToken ct)` method** -- Continuous audio output (per D-02, D-05, D-06):
    - Get backend from a dedicated `AudioPlaybackManager` (the main one, NOT capture mode).
    - `backend.EnsureInitialized(sampleRate, channels)`.
    - `const int chunkSamples = 4096;` (matches existing PulseAudio chunk size).
    - `int position = 0;` -- current sample index in `_currentBuffer`.
    - Loop while not cancelled:
      - Read current buffer via `Volatile.Read(ref _currentBuffer)`. If null, `Thread.Sleep(10); continue;`.
      - **Bar boundary check:** If `_pendingBuffer` is not null AND `IsBarBoundary(position)`:
        - `var newBuf = Interlocked.Exchange(ref _pendingBuffer, null);`
        - If newBuf is not null:
          - Apply micro-crossfade (64 samples, ~1.5ms) between old buffer tail and new buffer start to prevent clicks (research Pitfall 5).
          - `Volatile.Write(ref _currentBuffer, newBuf);`
          - Update `_currentTempo`, `_currentBeatsPerBar` from `_pendingMusicalContext`.
          - `position = 0;` (per D-06: start from beginning).
          - Print "Reloaded at bar {barNumber}" (per D-09).
      - Calculate chunk size: `Math.Min(chunkSamples, buffer.Length - position)`.
      - Call `backend.WriteChunk(buffer, position, chunkSize, sampleRate, channels)`.
      - `position += chunkSize;`
      - If `position >= buffer.Length`: `position = 0;` (loop the buffer continuously).

    **`IsBarBoundary(int samplePosition)` method:**
    - `double secondsPerBeat = 60.0 / _currentTempo;`
    - `double secondsPerBar = secondsPerBeat * _currentBeatsPerBar;`
    - `int samplesPerBar = (int)(secondsPerBar * _currentSampleRate) * _currentChannels;`
    - If `samplesPerBar <= 0` return true (safety).
    - Return `(samplePosition % samplesPerBar) < chunkSamples` (within one chunk of boundary per research Pattern 2).
    - Also compute and return the bar number: `samplePosition / samplesPerBar + 1`.

    **`TriggerBackgroundRender()` method** (per D-04, D-10, D-11, D-12):
    - Debounce: check `DateTime.Now - _lastChangeTime < 500ms`, return if too soon.
    - `_lastChangeTime = DateTime.Now;`
    - `Thread.Sleep(100);` (allow file write to complete, same as existing pattern).
    - Spawn `Task.Run`:
      - Read file contents.
      - Create a NEW `FlowEngine()` (per D-12 -- own instance, thread-safe).
      - Set `engine.AudioManager.CaptureMode = true` (per research Pitfall 2 -- no PulseAudio from background).
      - If `_deviceName` is set, configure device.
      - Call `engine.Execute(source, filePath)`.
      - If execution fails (per D-07, D-08): print error in red with "Error -- keeping previous version" prefix (per D-09). Return without setting pending buffer.
      - If success: `engine.AudioManager.GetCapturedBuffer()`. If null, print "No audio output detected -- playback continues with previous version." Return.
      - Extract musical context from `engine.Context.GetMusicalContext()`.
      - Set `_pendingMusicalContext = musicalContext;`
      - `Interlocked.Exchange(ref _pendingBuffer, capturedBuffer.Data);`
      - Also store sampleRate/channels from the captured buffer if they differ.
      - Dispose the background engine.

    **`Dispose()` method:** Cancel CTS, wait for playback task, dispose watcher, dispose any held resources.

    The class should implement `IDisposable`.
