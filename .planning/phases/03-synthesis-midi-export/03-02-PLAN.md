    **Key signature lookup table** (per D-12, Pitfall 5):

    **Note track generation:**
    Walk the song hierarchy per Pitfall 6 (section repeats):

    For each `SongSectionRef` in `song.Sections`:
    - Look up `SectionData` from `song.SectionRegistry`
    - Get context: tempo, time sig, key from `sectionData.Context`
    - For each repeat (0 to `sectionRef.RepeatCount`):
      - For each `SequenceData` in the section's `Sequences` dict:
        - For each `BarData` in `sequence.Bars`:
          - For each `MusicalNoteData` in `bar.MusicalNotes`:
            - Skip if `note.IsRest`
            - Convert to MIDI note: `PitchConversion.GetMidiNote(note.NoteName, note.Octave, note.Alteration)`
            - Convert velocity: `(byte)Math.Clamp((int)(note.Velocity * 127), 1, 127)` (per D-13, min 1 because MIDI vel 0 = note off)
            - Convert duration to ticks: `(long)(note.GetBeats(timeSigDenominator) * 480)` (per D-14). Handle dotted notes (GetBeats already accounts for this).
            - Collect as `(absoluteTickPosition, midiNote, velocity, durationTicks)` tuples
        - Track absolute tick position across bars by accumulating bar durations

    After collecting all note events for a section, sort by absolute tick position, then convert to NoteOn/NoteOff pairs with delta times. Or use DryWetMidi's `NoteEvent` approach:

    **Recommended DryWetMidi approach:** Use `TimedEvent` wrapper to set absolute time, then let DryWetMidi handle delta encoding:
    ```csharp
    using Melanchall.DryWetMidi.Core;
    using Melanchall.DryWetMidi.Interaction;

    var timedEvents = new List<TimedEvent>();
    // Add NoteOnEvent at absoluteTick, NoteOffEvent at absoluteTick + durationTicks
    // Then: var trackChunk = timedEvents.ToTrackChunk();
    ```
    This avoids Pitfall 3 (manual delta time calculation).

    **Create one track per section** (per D-12). Use MIDI channel 0 for melodic instruments, channel 9 (0-indexed) for drums.

    Note: The current `SectionData` does not store an instrument name per section. For v1, export all sections as piano (D-16). The `synthType` string is only passed to `renderSong` at render time, not stored in the Song data structure.
