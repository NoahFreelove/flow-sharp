<objective>
Wire the per-proc strict bit through parse-time AST capture (D-02/D-03) and through the call dispatch boundary (D-05). After this plan, every `ProcDeclaration` AST node carries its declaring file's strict bit, the Interpreter sets `ctx.StrictMode` to the proc's bit on entry (restored on exit), and the ExpressionEvaluator snapshots `ctx.CallerStrictMode = ctx.StrictMode` immediately before each builtin/proc invocation. Plans 44-03 (OverloadResolver) and 44-05..44-08 (Axis B + Axis C leaf sites) consume these two bits without further plumbing.

Purpose: lock the two-bit design (D-02 file-scope StrictMode + D-05 call-site CallerStrictMode) before any tier-disable or stdlib leaf-site rewrites depend on it. This is the architectural decision point — get the snapshot semantics right once.

Output: One AST record field, one Parser threading line, one push/pop pair in Interpreter, one save/restore pair in ExpressionEvaluator (covering both unqualified + Phase 43 qualified-call branches), two Phase44 test files.
</objective>
