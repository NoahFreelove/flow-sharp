<objective>
Build MIDI clock master + slave on the Plan 01 spine. The master is the ONLY genuinely-new mechanism in this phase: a dedicated 24-PPQN timing thread (`Stopwatch`-deadline + short final spin-wait, NOT `Thread.Sleep`) that reads `MusicalContext.Tempo` and emits raw clock bytes through the Open-Q1-resolved access path. The slave reuses the OSC `StartListener` lifecycle verbatim: a background `Task` + `Cts` that counts incoming 0xF8 pulses, derives BPM with an 8-pulse settle, and drives `MusicalContext.Tempo`. Both return `OscHandle`-modeled reference-identity handles.

Purpose: Tempo sync with drum machines / hardware sequencers / DAWs (CLOCK-01/02, D-40-03/05). Master⊕slave is a stateful session mode switchable only at bar boundary.
Output: `MidiClock.cs` + `MidiClockFunctions.cs` + `ClockHandleData.cs` + `ClockHandleType.cs`; edits to Value, FlowEngine, midi.flow, csproj; ClockMaster + ClockSlave tests.
</objective>
