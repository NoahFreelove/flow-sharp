    Create `examples/tutorial.flow` (per D-07, D-08, D-09, D-10, D-11, D-12):

    A single, self-contained Flow script that teaches the language progressively. It is a regular Flow script (per D-12) that prints explanatory text (per D-09) and runs working demonstrations.

    Use `//` line comments for code annotations (per D-10) and `$"..."` string interpolation for dynamic output (per D-10).

    Structure the tutorial in these progressive sections (per D-08):

    **1. Welcome and Setup**
    - Print a welcome banner
    - Explain what Flow is (a music programming language)
    - `use "@std"`, `use "@audio"` etc.

    **2. Basic Expressions and Variables**
    - Declare Int, Float, Double, String, Bool variables
    - Show arithmetic: `(add 1 2)`, `(mul 3.0 4.0)`
    - Show string interpolation: `$"The answer is {(str result)}"`
    - Show comparisons and boolean logic

    **3. Functions (procs)**
    - Define a simple proc that doubles a number
    - Show calling it
    - Show the flow operator `->`: `5 -> double`
    - Chain multiple functions with `->`

    **4. Collections and Loops**
    - Create an array literal
    - Use `for` loop to iterate
    - Use `map`, `filter`, `reduce`
    - Show `while` loop

    **5. Note Streams (the fun part)**
    - Explain notes: `C4`, `D4`, `E4` (note name + octave)
    - Explain durations: `q` (quarter), `h` (half), `w` (whole), `e` (eighth)
    - Create a simple melody: `| C4q D4q E4q F4q |`
    - Show rests with `_`
    - Show chords in brackets: `[C4 E4 G4]q`

    **6. Musical Context**
    - `tempo 120 { ... }` -- set BPM
    - `timesig 4/4 { ... }` -- set time signature
    - `key Cmajor { ... }` -- set key
    - Show how context nests and affects rendering

    **7. Sections and Songs**
    - Define sections: `section intro { ... }`
    - Create a Song: `Song s = [intro verse chorus]`
    - Render: `(renderSong s "piano")`
    - Show visualization: `-> visualize`

    **8. Effects and Export**
    - Show `reverb`, `lowpass`, `gain` effects
    - Chain effects with `->`: `buffer -> (reverb 0.3) -> (lowpass 2000.0)`
    - Export with `writeWav`

    **9. Graduation Piece (per D-11)**
    - Build a complete mini-composition that combines:
      - A chord progression (using `progression` keyword if available, or manual chords)
      - A melody section
      - An outro section
      - Effects processing
      - WAV export to `/tmp/flow_tutorial_output.wav`
    - Print a congratulations message with the export path

    Guidelines:
    - Keep each section focused -- print a section header, explain, demonstrate, print results
    - Use real musical examples that sound good (not just C C C C)
    - Print blank lines between sections for readability
    - Total script should be 150-250 lines
    - Everything must actually run without errors
    - No special runtime mode -- just a regular .flow script (per D-12)
    - Make it fun -- use encouraging language, musical metaphors
