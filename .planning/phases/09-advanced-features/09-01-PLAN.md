Implement the `tempoRamp` built-in function that renders a Sequence to a Buffer with linearly interpolated BPM across beats, producing smooth ritardando/accelerando audio output.

Purpose: Enables gradual tempo transitions (e.g., a song that slows from 120 to 80 BPM) -- a fundamental musical expression missing from the current constant-BPM rendering.
Output: Working `tempoRamp` function callable from Flow scripts, with test coverage.
</objective>

  <action>
    Create `flow-lang/StandardLibrary/Audio/TempoRampRenderer.cs` (per D-01, D-02, D-03, D-04):

    1. New static class `TempoRampRenderer` in namespace `FlowLang.StandardLibrary.Audio`.

    2. Public static method `Register(InternalFunctionRegistry registry)`:
       - Register two overloads (per D-06):
         - `tempoRamp(Sequence, Double, Double)` -> Buffer (defaults to "piano")
         - `tempoRamp(Sequence, Double, Double, String)` -> Buffer (explicit instrument)

    3. Private static method `Render(SequenceData sequence, double startBpm, double endBpm, string synthType)`:
       - Get timeline from `sequence.ToTimeline()` -- this gives `List<(BarData bar, double offsetBeats)>`.
       - Walk through each bar. For each bar, compute its position as a fraction `t` of total beats (use bar's offsetBeats / sequence.TotalBeats).
       - Compute interpolated BPM for this bar: `bpm = startBpm + t * (endBpm - startBpm)` (per D-03, linear interpolation).
       - Render the bar's voices using `BarRenderer.RenderBarAtBeat(bar, 0.0, synthType, sampleRate, bpm)` -- offset 0 since we position manually.
       - Mix voices to a stereo buffer using `SongRenderer.MixVoicesToStereoBuffer(voices, bpm, sampleRate, barBeats)`.
       - Concatenate all bar buffers sequentially using Array.Copy (same pattern as SongRenderer.AppendBuffers -- duplicate the helper locally since it's private).
       - Return the concatenated buffer as `Value.Buffer(result)`.

    4. Constants: `DefaultSampleRate = 44100`, `StereoChannels = 2`.

    5. Handle edge cases: empty sequence returns empty buffer, single-beat sequence uses startBpm.

    Register in `BuiltInFunctions.cs` (per D-05):
    - In `RegisterAudio` method, add call to `TempoRampRenderer.Register(registry)` near the end (follow SongRenderer.Register pattern).

    ```
    internal proc tempoRamp(Sequence: seq, Double: startBPM, Double: endBPM)
    internal proc tempoRamp(Sequence: seq, Double: startBPM, Double: endBPM, String: instrument)
    ```
