      Create `flow-lang/StandardLibrary/Notation/LilyPondExport.cs` (namespace `FlowLang.StandardLibrary.Notation`). Public method `public static void WriteLilyPond(string filepath, SongData song)`.

      Emit shape (template; substitute `{}` placeholders by walking the SongData):
      ```
      \version "2.24.0"
      \score {
        <<
          \new Staff = "{seqName1}" {
            \tempo 4 = {bpm}
            \time {n}/{d}
            \key {root} \{major|minor}
            \new Voice = "v1" { {notes1} }
            % when bar.ParallelVoices != null && Count > 1:
            % << \new Voice { {voice1-notes} } \\ \new Voice { {voice2-notes} } >>
          }
          \new Staff = "{seqName2}" { ... }
        >>
        \layout { }
        \midi { }
      }
      ```

      Note emit: for each `MusicalNoteData`:
      - If `IsRest`: emit `r{duration}`.
      - Else: emit `{LilyPondPitch.ToLilyPondPitch(NoteName, Alteration, Octave)}{LilyPondPitch.ToLilyPondDuration(DurationValue, IsDotted)}`.
      - If `CentOffset != null && CentOffset != 0`: append ` % {+N|-N}c` (where N = `(int)Math.Round(CentOffset.Value)`, with sign per D-39-12 + Pitfall 2).
      - Append articulation per D-v1.5-08 table: `Accent` → `->`, `Marcato` → `-^`, `Staccato` → `-.`, `Tenuto` → `--`, `Sforzando` → `\sfz`, `Legato` → `(` on first slur note, `)` on last. (LilyPond articulations are attached after the note + duration suffix.) Use the per-voice slur counter to handle Legato runs.
      - Separate notes by single space.

      Bar lines: insert `|` between bars within a voice. Final `|` at end of voice.

      Key signature: map Flow `Cmajor` / `Aminor` / `Fsharpmajor` / etc. to LilyPond `c \major` / `a \minor` / `fis \major`. Reuse the MusicXML key map's mode classification — implement a small parallel map here (or delegate to a shared helper if Plan 39-01 already extracted one).

      Tuplet handling: when emitting a sequence of notes that share a `DurationFraction`, wrap them in `\tuplet {numerator}/{denominator} { ... }`. If multiple nested tuplet groups exist, multiply the ratios per D-39-11 (Plan 39-02 v1.5 scope: flat tuplets are sufficient; the multiply-and-flatten code path is documented in a comment but only emits a single `\tuplet` per group from Flow's currently-flat `DurationFraction` model — Phase 36 didn't introduce nested tuplets).

      Determinism: walk Sections in `song.Sections` order (already insertion-ordered list); within each Section, iterate `Sequences` (insertion-ordered Dictionary). Use `StringBuilder` with explicit `\n` for newlines (no environment-dependent `Environment.NewLine`).
