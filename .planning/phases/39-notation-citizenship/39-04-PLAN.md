    <action>
      Create `flow-lang/StandardLibrary/Notation/MmlImport.cs` (namespace `FlowLang.StandardLibrary.Notation`). Public method `public static SequenceData ParseMml(string source)`.

      Implementation strategy: single-pass character-by-character interpreter with state:
        - `int octave = 4` (default O4)
        - `int defaultLengthN = 4` (default L4 = quarter)
        - `double tempo = 120.0` (default T120 — used to populate the Sequence's MusicalContext)
        - `Stack<(int loopStart, int iterationsRemaining)> loopStack = new()` — bounded at depth 16
        - `int expandedNoteCount = 0` — bounded at 65536
        - `List<MusicalNoteData> bufferedNotes = new()` — accumulates notes for the current loop iteration (or top-level)

      Token dispatch (case-insensitive notes letters? — actually MML is case-significant: lowercase a-g are notes, uppercase letters are commands; we follow PC-98 convention with both treated as notes for charitable input. Document decision in XML doc.):
        - `a..g`: emit note. Read trailing accidental (`+`, `#` = sharp; `-` = flat), trailing length digits (override `defaultLengthN`), trailing dot `.` (1.5× length), trailing tie `&`. Construct `MusicalNoteData` with current octave, accidental → Alteration (`+1` / `-1`), length → DurationValue (map N → NoteValue: 1→WHOLE, 2→HALF, 4→QUARTER, 8→EIGHTH, 16→SIXTEENTH, 32→THIRTYSECOND). Append to bufferedNotes. Increment expandedNoteCount.
        - `r` or `R`: emit rest with same length-parsing rules.
        - `O`: read next digit(s) — set octave (clamp to 0..8 per PC-98 range).
        - `>`: octave += 1.
        - `<`: octave -= 1.
        - `L`: read next digit(s) — set defaultLengthN.
        - `T`: read next digit(s) — set tempo.
        - `[`: push loop frame (loopStart = bufferedNotes.Count). If `loopStack.Count >= 16` → WarnOnce, treat the `[` as a no-op (collapse).
        - `]`: read trailing digit(s) for iteration count (default 1). Pop loop frame; replicate the notes added since loopStart `iterations - 1` more times (the first iteration was the in-place walk). Cap-check expandedNoteCount; if would exceed 65536, WarnOnce + truncate.
        - `,`, ` `, `\t`, `\n`: whitespace, skip.
        - Anything else: unknown opcode — read up to next whitespace as `token`, WarnOnce. Advance.

      Build the SequenceData at end:
        - One Bar containing all bufferedNotes (the Bar's TimeSignature defaults to 4/4 since MML has no meter notion; Sequence's MusicalContext gets Tempo = parsed tempo). Use synthetic name `"mml"`.

      Defensive: wrap the whole walk in `try` / `catch (Exception ex) { WarnOnce("mml-parse:{source.Substring(0,Math.Min(40,source.Length))}", $"[mml] parse error: {ex.Message}"); return new SequenceData(...empty...); }`.
    </action>
