Algorithm per RESEARCH §Pattern 4:
1. Compute `grainSamples = (int)(grainSeconds * input.SampleRate)`.
2. Compute `grainPeriodSamples = (int)(input.SampleRate / densityHz)` (period between grain emit times when jitter=0).
3. Allocate `result = new AudioBuffer(input.Frames, input.Channels, input.SampleRate)`.
4. Per channel: pre-compute a single `float[] windowCurve` of length `grainSamples` via `WindowFunctions.Hann/Gaussian/Tukey(grainSamples)` based on `window` enum.
5. For each grain emit time `t = 0, grainPeriodSamples, 2*grainPeriodSamples, ...` up to `input.Frames`:
   - `double offsetDraw = prng.NextDouble(site, "granular_offset") * 2.0 - 1.0;  // [-1, +1]`
   - `double timeDraw = prng.NextDouble(site, "granular_timing") * 2.0 - 1.0;`
   - `int sourceFrame = clamp(t + (int)(offsetDraw * jitter * grainSamples), 0, input.Frames - 1)` (per RESEARCH Pattern 4 jitter envelope formula).
   - `int emitFrame = clamp(t + (int)(timeDraw * jitter * grainPeriodSamples), 0, input.Frames - 1)`.
   - Overlap-add a single grain: `for k in [0, grainSamples) and emitFrame+k < input.Frames: result.Data[(emitFrame+k)*channels + ch] += input.Data[(sourceFrame+k)*channels + ch] * windowCurve[k]` (clamp source index too).
