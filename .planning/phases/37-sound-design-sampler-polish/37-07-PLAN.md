Note:  Chapter: Stretch + PitchShift (Phase 37 DSP-02 + DSP-03)

Note: ============================================================
Note:
Note:  Flow's stretch builtin time-stretches a Buffer without pitch
Note:  change; pitchShift shifts pitch without time change. Three modes:
Note:    #vocoder  — phase vocoder for harmonic material
Note:    #psola    — pitch-synchronous OLA for percussive material
Note:    #auto     — HPS (Fitzgerald 2010) picks per-frame; emits a
Note:                one-shot stderr advisory like:
Note:                  [stretch] mode=#auto picked: 73% vocoder / 27% psola

Note: -----------------------------------------------------------
Note: 1. Build a Buffer with mixed harmonic + transient content
Note: -----------------------------------------------------------
Buffer base = (createSineTone 2.0 440Hz 0.4)

Note: -----------------------------------------------------------
Note: 2. Stretch by 2x in vocoder mode (good for sine — phase locking)
Note: -----------------------------------------------------------
Buffer s_voc = (stretch base 2.0 mode=#vocoder)

Note: -----------------------------------------------------------
Note: 3. Stretch by 2x in psola mode (would preserve transients)
Note: -----------------------------------------------------------
Buffer s_psola = (stretch base 2.0 mode=#psola)

Note: -----------------------------------------------------------
Note: 4. Stretch by 2x in #auto — watch stderr for the advisory line
Note: -----------------------------------------------------------
Buffer s_auto = (stretch base 2.0 mode=#auto)

Note: -----------------------------------------------------------
Note: 5. Pitch-shift up 5 semitones via #auto (duration preserved)
Note: -----------------------------------------------------------
Buffer p_up = (pitchShift base +5st mode=#auto)

Note: -----------------------------------------------------------
Note: 6. Identity fast-paths — byte-identical output
Note: -----------------------------------------------------------
Buffer s_identity = (stretch base 1.0)
Buffer p_identity = (pitchShift base 0c)

Note: -----------------------------------------------------------
Note: 7. Mix for final output (vocoder + psola + auto + pitched)
Note: -----------------------------------------------------------
Buffer mix = (mix s_voc s_psola)
Buffer mix2 = (mix mix s_auto)
Buffer mix3 = (mix mix2 p_up)
