**PhaseVocoder.cs** — no production analog (PATTERNS No Analog Found). Implement Laroche-Dolson 1999 per RESEARCH Pattern 1.

Namespace: `FlowLang.StandardLibrary.Audio.DSP`. Public static class `PhaseVocoder`.

Surface:
- `public static AudioBuffer Process(AudioBuffer input, double factor, int frameSize = 2048, int hopSize = 512, int overlap = 4)` — validate factor > 0 (throw `ArgumentException` "factor must be positive"); validate `frameSize` is power of 2 (delegate via try/catch around an internal Fft validation or check `(frameSize & (frameSize - 1)) == 0`); validate `hopSize >= 1`, `overlap >= 2`.

Algorithm per RESEARCH Pattern 1 sketch:
1. Compute synthesis hop `synthHop = (int)Math.Round(hopSize * factor)`; output length `outLen = (int)Math.Round(input.Frames * factor) + frameSize`.
2. Pre-compute `float[] sqrtHann = WindowFunctions.Hann(frameSize).Select(v => MathF.Sqrt(v)).ToArray()` — sqrt-Hann for COLA reconstruction (CCRMA convention).
3. Per channel `ch`:
   - Extract `float[] channelInput` via stride extraction (mono: copy `Data`; stereo: copy every 2nd sample starting at `ch`).
   - Initialize `double[] prevPhase = new double[frameSize/2 + 1]`, `double[] phaseAccum = new double[frameSize/2 + 1]`.
   - For each analysis frame at position `t = 0, hopSize, 2*hopSize, ...` up to `channelInput.Length`:
     - Build `float[frameSize] frame`; zero-pad if past end.
     - Multiply by `sqrtHann`.
     - `Fft.Forward(frame, out double[] re, out double[] im)`.
     - Compute `double[] mag[k] = Math.Sqrt(re[k]*re[k] + im[k]*im[k])` and `double[] ph[k] = Math.Atan2(im[k], re[k])` for `k in [0, frameSize/2]`.
     - Per-bin inst freq: `phaseDelta = ph[k] - prevPhase[k]`; subtract expected `k * 2*pi * hopSize / frameSize`; wrap to `[-pi, pi]`; add back; divide by hopSize → `freq[k]`.
     - **Identity phase locking** (Pattern 1 phase-locking refinement): scan magnitude peaks (`mag[k] > mag[k-1] && mag[k] > mag[k-2] && mag[k] > mag[k+1] && mag[k] > mag[k+2]` per Laroche-Dolson definition); for each peak's region of influence (halfway to next peak on each side), all bins in the region take the peak's `phaseAdvance = freq[peak] * synthHop`. Then `phaseAccum[k] += phaseAdvance`.
     - Reconstruct: `re[k] = mag[k] * Math.Cos(phaseAccum[k])`; `im[k] = mag[k] * Math.Sin(phaseAccum[k])`. Mirror bins `[frameSize/2+1, frameSize-1]` as conjugates of `[1, frameSize/2-1]` for real-valued ifft.
     - `Fft.Inverse(re, im, out float[] outFrame)`.
     - Multiply `outFrame` by `sqrtHann` again.
     - Overlap-add into channel output at synthesis position `(int)Math.Round(t * factor)`.
     - `prevPhase = ph` for next iteration.
4. Re-pack channel outputs into `new AudioBuffer(outLen, input.Channels, input.SampleRate)`; return.

- `private static float[] ProcessChannel(float[] input, double factor, int frameSize, int hopSize, float[] sqrtHann)` — per-channel state.
- `private static int[] PickPeaks(double[] magnitude)` — peak picker returning sorted bin indices.

YIN per Pattern 2 (unchanged — runs only when `pitchPeriodOverride` is null):
1. Difference function `d(tau) = Sum_{n=0..N-tau} (x[n] - x[n+tau])^2` for `tau in [1, N/2]`.
2. Cumulative mean normalized difference `dPrime(tau) = d(tau) / ((1.0/tau) * Sum_{j=1..tau} d(j))` (penalizes octave-0 spurious low peak per Pitfall 3).
3. Scan `dPrime` for first tau where `dPrime[tau] < yinThreshold`; return tau; else return -1.

PSOLA loop per Pattern 2 **with W4 LOCK threading**:
1. **W4 LOCK**: if `pitchPeriodOverride.HasValue`, use that single period throughout (no per-window DetectPitchPeriod calls). Else, compute epoch positions: every 1024 samples, run DetectPitchPeriod on that window; if voiced, find local maxima at intervals of `period` (peak-pick); if unvoiced, mark epochs at intervals of defaultPeriodSamples.
2. Allocate `result = new AudioBuffer((int)Math.Round(input.Frames * factor), input.Channels, input.SampleRate)`.
3. For each input epoch at position `inEpoch`:
   - Compute `outEpoch = (int)Math.Round(inEpoch * factor)`.
   - **W4 LOCK**: grain length is `windowSizeOverride ?? (2 * effectivePeriod)` where `effectivePeriod = pitchPeriodOverride ?? detectedPeriod ?? defaultPeriodSamples`.
   - Extract `grainLen` samples centered on `inEpoch`; multiply by `WindowFunctions.Hann(grainLen)`.
   - Overlap-add into result at `outEpoch`.
4. Return result.

**StretchEngine.cs** — Namespace `FlowLang.StandardLibrary.Audio.DSP`. Public enum `StretchMode { Vocoder, Psola, Auto }`. Public static class `StretchEngine`.

Surface (W4 LOCK):
```

    AudioBuffer input,
    double factor,
    StretchMode mode = StretchMode.Auto,
    int frameSize = 2048,            // vocoder knob
    int hopSize = 512,                // vocoder knob
    int overlap = 4,                  // vocoder knob
    double transientThreshold = 0.3,  // auto knob
    int? pitchPeriod = null,          // W4 LOCK — psola knob
    int? windowSize = null,           // W4 LOCK — psola knob

```

Algorithm:
1. Validate factor > 0 (throw ArgumentException "stretch factor must be positive; got X"). If `Math.Abs(factor - 1.0) < 1e-12` return input verbatim (Pitfall 11 identity fast-path).
2. Switch on mode:
   - **Vocoder** (W4 LOCK): `return PhaseVocoder.Process(input, factor, frameSize, hopSize, overlap);` — all 3 vocoder knobs threaded.
   - **Psola** (W4 LOCK): `int defaultPeriod = 441; return Psola.Process(input, factor, defaultPeriod, pitchPeriod, windowSize);` — both psola knobs threaded as overrides.
   - **Auto**: do the per-frame dispatch path below.
3. **Auto path** (Pattern 3) — also threads ALL knobs through to the chosen sub-engine:
   - Compute STFT spectrogram: per frame at `t = 0, hopSize, 2*hopSize, ...` extract `frameSize` samples, window via Hann, Fft.Forward, take magnitudes for bins [0, frameSize/2]; collect into `float[][] spectrogram` (frame major, bin minor).
   - `int horizKernel = Math.Max(1, (int)Math.Round(17.0 * frameSize / 2048.0))`; same for vertKernel (Pitfall 4 scaling).
   - `double[] ratios = Hps.ComputePercussiveRatio(spectrogram, horizKernel, vertKernel)`.
   - Decide per frame: `bool[] usePsola = ratios.Select(r =&gt; r &gt; transientThreshold).ToArray()`.
   - Render: SIMPLEST viable shape (RESEARCH §Pattern 3 binary per-frame): run vocoder for the whole buffer with `(frameSize, hopSize, overlap)`, run psola for the whole buffer with `(pitchPeriod, windowSize)` (overrides forwarded), then per-output-frame select from one OR the other based on the source frame's classification (since output is also frame-by-frame at synthHop positions). Use a one-frame crossfade at boundaries (sqrt-Hann blend) to avoid clicks.
   - Compute summary: `int vocoderCount = usePsola.Count(x =&gt; !x)`; `int psolaCount = usePsola.Length - vocoderCount`; `int pctVoc = vocoderCount * 100 / usePsola.Length`; `int pctPso = 100 - pctVoc`.
   - Emit advisory via RenderingDiagnostics.WarnOnce with sentinel `$"stretch:auto:{site}:{pctVoc}/{pctPso}"` (per OQ5 resolution) and message `$"[stretch] mode=#auto picked: {pctVoc}% vocoder / {pctPso}% psola across {usePsola.Length} frames"`.
4. Return blended result.
