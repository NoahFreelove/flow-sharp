The walker is purely lexical — no parser, no evaluator. It re-uses `flow-lang/Lexing/SimpleLexer.cs` and reads/writes source text directly.

Critical correctness properties:
- **Idempotent.** Running twice produces zero diff. Structurally guaranteed: `(add a b)` has no Plus/Minus token between value-producing tokens.
- **Note-stream safe.** Inside `| ... |` regions, ALL Plus/Minus/Star/Slash tokens are pass-through (Pitfall 3). Note streams have their own typed-literal arithmetic (`-3dB`, `+50c`, `C4/12`).
- **Precedence-aware.** Star/Slash binds tighter than Plus/Minus, mirroring the deleted `ParseAdditive`/`ParseMultiplicative`.
- **String-concat defensive.** `"abc" + x` → `(concat "abc" x)`, even though RESEARCH found zero such call sites in the repo.
- **Unary handling.** `-IDENT` → `(neg IDENT)`; `+IDENT` → `IDENT` (silent strip per D-03).

    The implementation has 5 logical sections:
    1. CLI entry: glob expand args (files + directories) into a list of `.flow` files
    2. Per-file `Migrate(source) -> string` that runs the walker and returns rewritten source
    3. Token classification helpers: `IsValueProducing(TokenType)`, `IsExpressionStart(TokenType)`, `IsArithOp(TokenType)`
    4. Precedence climber: detects infix arithmetic spans inside the token stream (skipping Pipe...Pipe regions) and emits prefix-form replacements

    Full implementation (use this as the executor's blueprint; rename helpers freely but keep the logical structure):

    ```csharp
    using System.Text;
    using FlowLang.Lexing;
    using FlowLang.Diagnostics;

    namespace FlowLang.Migrate26;

    internal static class Program
    {
        static int Main(string[] args)
        {
            if (args.Length == 0)
            {
                Console.Error.WriteLine("Usage: dotnet run --project scripts/Migrate26 -- <file-or-dir> [...]");
                Console.Error.WriteLine("Migrates infix arithmetic in .flow files to prefix form.");
                return 1;
            }

            var files = ExpandPaths(args);
            int touched = 0, skipped = 0;
            foreach (var file in files)
            {
                string before = File.ReadAllText(file);
                string after;
                try { after = Migrate(before); }
                catch (Exception ex)
                {
                    Console.Error.WriteLine($"ERROR migrating {file}: {ex.Message}");
                    return 2;
                }
                if (before != after)
                {
                    File.WriteAllText(file, after);
                    Console.WriteLine($"migrated: {file}");
                    touched++;
                }
                else
                {
                    skipped++;
                }
            }
            Console.WriteLine($"Done. {touched} migrated, {skipped} unchanged.");
            return 0;
        }

        static IEnumerable<string> ExpandPaths(string[] args)
        {
            foreach (var p in args)
            {
                if (Directory.Exists(p))
                {
                    foreach (var f in Directory.EnumerateFiles(p, "*.flow", SearchOption.AllDirectories))
                        yield return f;
                }
                else if (File.Exists(p) && p.EndsWith(".flow"))
                {
                    yield return p;
                }
                else
                {
                    Console.Error.WriteLine($"warning: skipping {p} (not a .flow file or directory)");
                }
            }
        }

        // ===== Per-file migration =====

        static string Migrate(string source)
        {
            var lexer = new SimpleLexer(source, new ErrorReporter());
            var tokens = lexer.Tokenize();
            return RewriteSpans(source, tokens);
        }

        // ===== Walker =====

        static string RewriteSpans(string source, List<Token> tokens)
        {
            // Compute byte offset of each token using line-offset table.
            int[] lineStart = ComputeLineStarts(source);
            int[] tokenOffset = new int[tokens.Count];
            for (int i = 0; i < tokens.Count; i++)
            {
                var loc = tokens[i].Location;
                int line = loc.Line - 1;     // 1-based -> 0-based
                int col = loc.Column - 1;
                tokenOffset[i] = (line >= 0 && line < lineStart.Length) ? lineStart[line] + col : 0;
            }

            // Detect spans of infix arithmetic at top level (NOT inside Pipe...Pipe).
            // For each detected span, build prefix-form replacement and record (start, end, text).
            var edits = new List<(int Start, int End, string Replacement)>();

            int idx = 0;
            int pipeDepth = 0;        // toggle on each Pipe; ODD = inside note stream
            while (idx < tokens.Count)
            {
                var t = tokens[idx];
                if (t.Type == TokenType.Pipe)
                {
                    pipeDepth++;
                    idx++;
                    continue;
                }
                if (pipeDepth % 2 == 1)
                {
                    // Inside note stream — pass through.
                    idx++;
                    continue;
                }

                // Try to detect an infix-arithmetic span starting at this token.
                if (IsExpressionStart(t.Type) || t.Type == TokenType.Minus || t.Type == TokenType.Plus)
                {
                    int spanEnd;
                    string? prefix = TryParseAdditiveSpan(tokens, idx, out spanEnd);
                    if (prefix != null && spanEnd > idx)
                    {
                        // Compute byte-range in source. Span starts at tokenOffset[idx], ends at end of token spanEnd-1.
                        int startOffset = tokenOffset[idx];
                        int endOffset = tokenOffset[spanEnd - 1] + tokens[spanEnd - 1].Text.Length;
                        // Ensure we actually changed something (idempotence guard).
                        string original = source.Substring(startOffset, endOffset - startOffset);
                        if (original != prefix)
                            edits.Add((startOffset, endOffset, prefix));
                        idx = spanEnd;
                        continue;
                    }
                }
                idx++;
            }

            // Apply edits in reverse so offsets stay valid.
            edits.Sort((a, b) => b.Start.CompareTo(a.Start));
            var sb = new StringBuilder(source);
            foreach (var (s, e, r) in edits)
            {
                sb.Remove(s, e - s);
                sb.Insert(s, r);
            }
            return sb.ToString();
        }

        static int[] ComputeLineStarts(string source)
        {
            var list = new List<int> { 0 };
            for (int i = 0; i < source.Length; i++)
                if (source[i] == '\n') list.Add(i + 1);
            return list.ToArray();
        }

        // ===== Precedence climber =====
        //
        // Mirrors deleted ParseAdditive / ParseMultiplicative:
        //   additive    := multiplicative ((Plus|Minus) multiplicative)*
        //   multiplicative := primary ((Star|Slash) primary)*
        //   primary     := IntLit | FloatLit | StringLit | Ident | NoteLit | (expr) | [...]
        //                | (Plus|Minus) primary    -- unary
        //
        // Returns the prefix-form text spanning [startIdx .. spanEnd) (exclusive). Returns
        // null if no infix arithmetic was found at startIdx (caller advances by 1).

        static string? TryParseAdditiveSpan(List<Token> tokens, int startIdx, out int spanEnd)
        {
            int idx = startIdx;
            string? lhs = TryParseMultiplicativeSpan(tokens, ref idx);
            if (lhs == null) { spanEnd = startIdx; return null; }

            bool sawAnyOp = false;
            while (idx < tokens.Count
                && (tokens[idx].Type == TokenType.Plus || tokens[idx].Type == TokenType.Minus)
                && (idx + 1 < tokens.Count) && IsExpressionStart(tokens[idx + 1].Type))
            {
                string op = tokens[idx].Type == TokenType.Plus ? "add" : "sub";
                // Special-case: String + value -> (concat ...)
                if (op == "add" && LooksLikeStringConcat(tokens, startIdx, idx))
                    op = "concat";
                idx++;
                string? rhs = TryParseMultiplicativeSpan(tokens, ref idx);
                if (rhs == null) { spanEnd = startIdx; return null; }
                lhs = $"({op} {lhs} {rhs})";
                sawAnyOp = true;
            }
            spanEnd = idx;
            return sawAnyOp ? lhs : null;   // Return null if there was no infix to rewrite.
        }

        static string? TryParseMultiplicativeSpan(List<Token> tokens, ref int idx)
        {
            string? lhs = TryParsePrimarySpan(tokens, ref idx);
            if (lhs == null) return null;

            while (idx < tokens.Count
                && (tokens[idx].Type == TokenType.Star || tokens[idx].Type == TokenType.Slash)
                && (idx + 1 < tokens.Count) && IsExpressionStart(tokens[idx + 1].Type))
            {
                string op = tokens[idx].Type == TokenType.Star ? "mul" : "div";
                idx++;
                string? rhs = TryParsePrimarySpan(tokens, ref idx);
                if (rhs == null) return null;
                lhs = $"({op} {lhs} {rhs})";
            }
            return lhs;
        }

        static string? TryParsePrimarySpan(List<Token> tokens, ref int idx)
        {
            if (idx >= tokens.Count) return null;

            // Unary minus on identifier -> (neg IDENT)
            if (tokens[idx].Type == TokenType.Minus
                && idx + 1 < tokens.Count
                && tokens[idx + 1].Type == TokenType.Identifier)
            {
                string name = tokens[idx + 1].Text;
                idx += 2;
                return $"(neg {name})";
            }
            // Unary plus on identifier -> just the identifier (D-03 silent strip)
            if (tokens[idx].Type == TokenType.Plus
                && idx + 1 < tokens.Count
                && tokens[idx + 1].Type == TokenType.Identifier)
            {
                string name = tokens[idx + 1].Text;
                idx += 2;
                return name;
            }

            var t = tokens[idx];

            // Parenthesised sub-expression: capture verbatim text, recurse semantics not needed
            // because the inner parens already delimit a complete expression that has its own arithmetic
            // (which will be picked up by the outer Migrate() pass on the same source — but wait, the
            // outer pass is single-shot. We need to recurse INSIDE the parens here.)
            if (t.Type == TokenType.LParen)
            {
                // Find matching RParen at same paren-depth.
                int depth = 1;
                int start = idx;
                idx++;
                while (idx < tokens.Count && depth > 0)
                {
                    if (tokens[idx].Type == TokenType.LParen) depth++;
                    else if (tokens[idx].Type == TokenType.RParen) depth--;
                    if (depth > 0) idx++;
                }
                if (idx >= tokens.Count) return null;
                idx++; // consume RParen

                // Recurse: the inner content might contain infix that needs migrating.
                int innerStart = start + 1, innerEnd = idx - 1;
                if (innerEnd > innerStart)
                {
                    var inner = tokens.GetRange(innerStart, innerEnd - innerStart);
                    string innerOriginal = TokensToText(inner);
                    int innerIdx = 0;
                    string? rewrittenInner = TryParseAdditiveSpan(inner, 0, out int e);
                    if (rewrittenInner != null && e == inner.Count)
                        return $"({rewrittenInner})";
                    // Otherwise emit the original verbatim (parens preserved, inner might be an existing
                    // prefix call which doesn't need migrating).
                    return $"({innerOriginal})";
                }
                return "()";
            }

            // Bracket-delimited sub-expression (array literal): capture verbatim
            if (t.Type == TokenType.LBracket)
            {
                int depth = 1;
                int start = idx;
                idx++;
                while (idx < tokens.Count && depth > 0)
                {
                    if (tokens[idx].Type == TokenType.LBracket) depth++;
                    else if (tokens[idx].Type == TokenType.RBracket) depth--;
                    if (depth > 0) idx++;
                }
                if (idx >= tokens.Count) return null;
                idx++; // consume RBracket
                return TokensToText(tokens.GetRange(start, idx - start));
            }

            // Atomic token — Identifier / IntLiteral / FloatLiteral / StringLiteral / NoteLiteral / BoolLiteral
            if (IsAtomicValueToken(t.Type))
            {
                string text = t.Text;
                // For StringLiteral, t.Text is the lexeme INCLUDING surrounding quotes (verify by reading
                // SimpleLexer — adjust if t.Text is the unquoted body).
                idx++;
                return text;
            }

            return null;
        }

        // ===== Token classification =====

        static bool IsValueProducing(TokenType t) =>
            t is TokenType.IntLiteral or TokenType.FloatLiteral or TokenType.StringLiteral
              or TokenType.NoteLiteral or TokenType.BoolLiteral or TokenType.Identifier
              or TokenType.RParen or TokenType.RBracket;

        static bool IsExpressionStart(TokenType t) =>
            t is TokenType.IntLiteral or TokenType.FloatLiteral or TokenType.StringLiteral
              or TokenType.NoteLiteral or TokenType.BoolLiteral or TokenType.Identifier
              or TokenType.LParen or TokenType.LBracket;

        static bool IsAtomicValueToken(TokenType t) =>
            t is TokenType.IntLiteral or TokenType.FloatLiteral or TokenType.StringLiteral
              or TokenType.NoteLiteral or TokenType.BoolLiteral or TokenType.Identifier;

        static bool LooksLikeStringConcat(List<Token> tokens, int startIdx, int opIdx)
        {
            // Crude heuristic: if any token in the LHS span is a StringLiteral, treat as concat.
            for (int i = startIdx; i < opIdx; i++)
                if (tokens[i].Type == TokenType.StringLiteral) return true;
            return false;
        }

        static string TokensToText(List<Token> tokens)
        {
            // Reconstruct source by joining token texts with single spaces.
            // (Slightly lossy on whitespace, but acceptable since the migration only edits
            //  spans that contained arithmetic.)
            return string.Join(" ", tokens.Select(t => t.Text));
        }
    }
    ```

    NOTE on lexer Token interface: read `flow-lang/Lexing/Token.cs` to confirm:
    - Property `Text` exists (the verbatim lexeme including quotes for StringLiteral)
    - Property `Location` exists with `.Line` and `.Column` (1-based)
    If `Token.Text` is the body without quotes for `StringLiteral`, the migration script's StringLiteral pass-through must reconstruct quotes. Adjust accordingly.

    NOTE on `LParen` recursion: the `TryParsePrimarySpan` LParen branch reconstructs inner content via `TokensToText(inner)`, which JOINS tokens with spaces. This is lossy for source containing semantically-significant whitespace. **Acceptable trade-off** because: (a) Flow's lexer treats whitespace as separator-only outside note streams, (b) the only case that matters here is the original infix expression being rewritten, where the outer-level rewrite catches the arithmetic. If problems arise during smoke testing, replace `TokensToText` with a byte-range-preserving version that copies the original `source.Substring(innerStartOffset, innerEndOffset - innerStartOffset)`.

    Special edge cases that may come up during smoke testing:
    1. **Note-stream typed literals** like `-3dB` inside `| ... |`: handled by the `pipeDepth % 2 == 1` skip — the walker never sees those tokens for rewriting.
    2. **Per-note `C4/12` fractional duration** inside `| ... |`: same — note streams pass through.
    3. **`(intToDouble bar)` style nested function call** — caught by the LParen recursion path, which captures inner content verbatim.
    4. **`a + b * c`** at top level — caught by the precedence climber: `TryParseMultiplicativeSpan` consumes `b * c` first, then `TryParseAdditiveSpan` wraps with `(add a (mul b c))`.
    5. **`-x` at expression start** (variable declaration RHS) — caught by `TryParsePrimarySpan` unary branch → `(neg x)`.
    6. **Already-prefix calls like `(add 1 2)`** — not migrated. The walker only triggers on raw `Plus|Minus|Star|Slash` tokens between value-producing tokens. `(add 1 2)` lexes as `LParen, Identifier, IntLiteral, IntLiteral, RParen` — no arithmetic ops in the span. Idempotent by construction.
