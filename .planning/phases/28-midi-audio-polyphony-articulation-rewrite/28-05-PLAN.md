<objective>
Add voice-pool allocation with default size 32, configurable per-section via `voicePool N { ... }` musical-context block. Range 1..256; out-of-range error. When pool exhausted: steal-oldest (truncate the voice with longest elapsed playtime).

Plumbing chain: lexer recognizes `voicePool` → token → parser dispatches to musical-context-statement → AST has `MusicalContextType.VoicePool` → interpreter validates 1..256 → MusicalContext.VoicePoolSize set → SequenceRenderer reads it → VoiceAllocator.AllocateWithPool applies steal-oldest.

Purpose: Bounded memory + CPU for dense polyphonic writing per SPEC-7. Steal-oldest preserves recent musical events (the head of new motifs) over old held notes that have already had their attack heard.
Output: Voice pool default 32, per-section override block, steal-oldest policy, deterministic across runs, integration test with 50-onset stress.
</objective>

```csharp
/// <summary>
/// Phase 28 SPEC-7: voice-pool allocation with steal-oldest policy. Walks voices in
/// onset order (sorted by Voice.OffsetBeats); maintains an active set bounded by
/// poolSize. When a new voice would exceed the pool, the active voice with the
/// EARLIEST onset (= "oldest" — has been audible longest) is truncated at the new
/// voice's onset and removed from the active set. Tiebreaker for equal onsets:
/// original input index (deterministic across runs).
///
/// Range: 1..256. Out-of-range raises ArgumentOutOfRangeException.
/// </summary>
public static List<Voice> AllocateWithPool(List<Voice> voices, int sampleRate, int poolSize, double bpm)
{
    if (poolSize < 1 || poolSize > 256)
        throw new ArgumentOutOfRangeException(nameof(poolSize),
            $"Voice pool size must be in [1, 256], got {poolSize}");
    if (voices.Count <= poolSize) return voices;

    double secondsPerBeat = 60.0 / bpm;

    // Sort by onset (deterministic: ThenBy original index)
    var ordered = voices
        .Select((v, i) => (voice: v, idx: i, onsetSec: v.OffsetBeats * secondsPerBeat))
        .OrderBy(x => x.onsetSec).ThenBy(x => x.idx)
        .ToList();

    // Active set: voices whose buffers haven't ended yet at the current iteration's onset.
    var active = new List<(Voice voice, int idx, double onsetSec, double endSec)>();
    var output = new List<Voice>(); // preserved (possibly mutated) voices in original ordering

    foreach (var (voice, idx, onsetSec) in ordered)
    {
        // Drop voices that ended before this onset
        active.RemoveAll(a => a.endSec <= onsetSec);

        if (active.Count >= poolSize)
        {
            // Steal oldest: smallest onsetSec, then smallest idx
            var oldest = active.OrderBy(a => a.onsetSec).ThenBy(a => a.idx).First();
            int truncFrames = Math.Max(0, (int)((onsetSec - oldest.onsetSec) * sampleRate));
            TruncateVoiceBuffer(oldest.voice, truncFrames, sampleRate);
            active.Remove(oldest);
        }

        double durSec = (double)voice.Buffer.Frames / sampleRate;
        active.Add((voice, idx, onsetSec, onsetSec + durSec));
        output.Add(voice);
    }

    // Preserve original ordering for downstream consumers
    return voices;
}

/// <summary>
/// Truncates a voice's buffer to newFrameCount samples, applying a 5ms fade-out at
/// the new end to prevent click artifacts. Frames beyond newFrameCount are zeroed.
/// </summary>
private static void TruncateVoiceBuffer(Voice voice, int newFrameCount, int sampleRate)
{
    int total = voice.Buffer.Frames;
    if (newFrameCount >= total) return;

    int fadeSamples = Math.Min((int)(0.005 * sampleRate), newFrameCount);
    // Apply fade-out to last fadeSamples of the kept range
    for (int i = 0; i < fadeSamples; i++)
    {
        int frame = newFrameCount - fadeSamples + i;
        float fadeGain = 1.0f - ((float)i / fadeSamples);
        for (int ch = 0; ch < voice.Buffer.Channels; ch++)
            voice.Buffer.SetSample(frame, ch, voice.Buffer.GetSample(frame, ch) * fadeGain);
    }
    // Zero frames beyond newFrameCount
    for (int frame = newFrameCount; frame < total; frame++)
        for (int ch = 0; ch < voice.Buffer.Channels; ch++)
            voice.Buffer.SetSample(frame, ch, 0f);
}
```

The return value is the original `voices` list (in original order) — voices over the pool size have been truncated in-place. This preserves the existing downstream contract that `SongRenderer.MixVoicesToStereoBuffer` iterates voices and mixes via offset. (Alternative: return only the surviving voices — but truncated-then-zeroed mixes correctly into the output anyway.)</action>
