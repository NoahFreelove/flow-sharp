    1. In `AudioCore.cs`, add a new `public static Value Mix(IReadOnlyList<Value> args)` method (per D-01):
       - Extract `bufferA = args[0].As<AudioBuffer>()` and `bufferB = args[1].As<AudioBuffer>()`
       - Per D-03: If channel counts differ, promote mono to stereo before mixing. To promote mono to stereo, create a new 2-channel AudioBuffer and duplicate the mono samples to both channels.
       - Per D-02: Output length = `Math.Max(bufferA.Frames, bufferB.Frames)`. Shorter buffer zero-pads implicitly (read 0f for out-of-range indices).
       - Per D-05: No gain normalization. Just sum samples: `result.Data[i] = sampleA + sampleB`.
       - Return `Value.Buffer(result)`.

    2. In `BuiltInFunctions.cs` `RegisterAudio` method, register the mix function:
       ```csharp
       var mixSignature = new FunctionSignature("mix", [BufferType.Instance, BufferType.Instance]);
       registry.Register("mix", mixSignature, Audio.AudioCore.Mix);
       ```
       Place it near the existing `mixBuffers` registration.

    3. Create `tests/test_mix.flow`:
       ```

       // Test basic mix of two mono buffers

       (print $"mix channels: {(getChannels mixed)}")

       // Test different length buffers (per D-02)

       (print "mix tests passed")
       ```
