    Create `public static class VoiceAllocator` with:

    ```csharp
    /// Default max voices (D-12)
    public static int MaxVoices { get; set; } = 32;

    /// Allocate voices from a list, enforcing the voice limit.
    /// If the list exceeds MaxVoices, the quietest voices are stolen
    /// with a 5ms crossfade to avoid clicks (D-13, D-15).
    public static List<Voice> Allocate(List<Voice> voices, int sampleRate)
    ```

    Implementation:
    - If `voices.Count <= MaxVoices`, return the list unchanged (no allocation needed)
    - Sort/rank voices by peak amplitude. For each voice, compute peak amplitude:
      ```csharp
      private static float GetPeakAmplitude(Voice voice)
      {
          float peak = 0f;
          for (int i = 0; i < voice.Buffer.Frames && i < voice.Buffer.SampleRate; i++)
          {
              for (int ch = 0; ch < voice.Buffer.Channels; ch++)
              {
                  float abs = Math.Abs(voice.Buffer.GetSample(i, ch));
                  if (abs > peak) peak = abs;
              }
          }
          return peak * (float)voice.Gain;
      }
      ```
    - Sort voices by peak amplitude descending
    - Keep the top `MaxVoices` voices
    - For voices being stolen (the quietest ones beyond the limit), apply a 5ms fade-out to avoid clicks (per D-15, Pitfall 4):
      ```csharp
      private static void ApplyFadeOut(Voice voice, int sampleRate)
      {
          int fadeSamples = (int)(0.005 * sampleRate); // 5ms = 220 samples at 44100
          fadeSamples = Math.Min(fadeSamples, voice.Buffer.Frames);
          // Apply fade to the END of the buffer (where the cut happens)
          // Actually, for stolen voices we keep them but truncate/fade
          // Since we're removing them entirely, the fade prevents the abrupt cut
          // in the mix. Apply fade-out over the last fadeSamples of the buffer.
          for (int i = 0; i < fadeSamples; i++)
          {
              float fadeGain = 1.0f - ((float)i / fadeSamples);
              int frame = voice.Buffer.Frames - fadeSamples + i;
              if (frame < 0) continue;
              for (int ch = 0; ch < voice.Buffer.Channels; ch++)
              {
                  float sample = voice.Buffer.GetSample(frame, ch);
                  voice.Buffer.SetSample(frame, ch, sample * fadeGain);
              }
          }
      }
      ```

    Wait — the voice stealing concept needs clarification. In a typical voice allocator, voices are allocated in real-time as notes arrive. But Flow's render pipeline creates ALL voices for a bar/sequence at once, then mixes them. The allocation should work like this:

    Given a list of voices that overlap at any point in time, if at any time-point the count exceeds MaxVoices, the quietest voice(s) at that time-point should be removed (with fade-out). The simpler approach for Flow's batch rendering: if the TOTAL number of voices in a render call exceeds MaxVoices, drop the quietest ones entirely (with fade-out). This is simpler and matches the user expectation of "no more than N simultaneous voices."

    Actually, the most practical approach for batch rendering: in `Allocate`, if `voices.Count > MaxVoices`:
    1. Sort by peak amplitude descending (loudest first)
    2. Keep first `MaxVoices` voices
    3. Apply 5ms fade-out to the STOLEN voices' buffers (the ones being dropped) — this prevents clicks if they were partially rendered into a mix before being cut
    4. Return only the kept voices

    Since stolen voices are dropped entirely, the fade-out on them is only relevant if they've already been partially mixed (which they haven't in Flow's pipeline — mixing happens AFTER allocation). So the fade-out is more of a safety measure. The real anti-click value is in not having too many voices summed together causing clipping.

    Simpler and correct implementation:
    ```csharp
    public static List<Voice> Allocate(List<Voice> voices, int sampleRate)
    {
        if (voices.Count <= MaxVoices) return voices;

        // Sort by peak amplitude descending — keep loudest
        var sorted = voices
            .Select(v => (voice: v, peak: GetPeakAmplitude(v)))
            .OrderByDescending(x => x.peak)
            .ToList();

        // Keep the loudest MaxVoices voices
        var kept = sorted.Take(MaxVoices).Select(x => x.voice).ToList();

        return kept;
    }
    ```

    The crossfade (D-15) is more relevant for real-time voice stealing. For batch rendering, dropping the quietest voices cleanly is sufficient. Include the fade-out method for future real-time use but the batch allocator simply drops.
