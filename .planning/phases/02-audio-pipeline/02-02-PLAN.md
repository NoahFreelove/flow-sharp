    **1. Create `DSP/Panner.cs`** (per D-05, D-16):

    Namespace: `FlowLang.StandardLibrary.Audio.DSP`

    Create `public static class Panner` with:
    ```csharp
    public static AudioBuffer Apply(AudioBuffer input, float pan)
    ```
    - Clamp pan to [-1.0, 1.0]
    - Map pan from [-1, 1] to [0, PI/2]: `float angle = (pan + 1f) * 0.25f * MathF.PI;`
    - Compute gains: `float leftGain = MathF.Cos(angle);` `float rightGain = MathF.Sin(angle);` (per D-05)
    - ALWAYS create stereo output: `var result = new AudioBuffer(input.Frames, 2, input.SampleRate)` (per Pitfall 2: mono must be promoted to stereo)
    - For each frame:
      - If input is mono: `mono = input.GetSample(frame, 0)`
      - If input is stereo: `mono = (input.GetSample(frame, 0) + input.GetSample(frame, 1)) * 0.5f` (downmix to mono, then re-pan)
      - `result.SetSample(frame, 0, mono * leftGain)`
      - `result.SetSample(frame, 1, mono * rightGain)`
    - Return result (new buffer, never mutates input per D-16)

    **4. Fix Voice.Pan bug in `SongRenderer.cs`** (per D-08):

    In `MixVoicesToStereoBuffer`, replace the current mixing loop (lines ~92-119) with constant-power panning per voice:

    ```csharp
    foreach (var voice in voices)
    {
        int voiceStartFrame = (int)(voice.OffsetBeats * secondsPerBeat * sampleRate);

        // Constant-power panning (D-05, D-08)
        float panAngle = (float)((voice.Pan + 1.0) * 0.25 * Math.PI);
        float leftGain = MathF.Cos(panAngle) * (float)voice.Gain;
        float rightGain = MathF.Sin(panAngle) * (float)voice.Gain;

        for (int frame = 0; frame < voice.Buffer.Frames; frame++)
        {
            int destFrame = voiceStartFrame + frame;
            if (destFrame < 0 || destFrame >= totalFrames) continue;

            // Get mono sample from voice (sum channels if stereo)
            float sample;
            if (voice.Buffer.Channels == 1)
            {
                sample = voice.Buffer.GetSample(frame, 0);
            }
            else
            {
                sample = 0f;
                for (int ch = 0; ch < voice.Buffer.Channels; ch++)
                    sample += voice.Buffer.GetSample(frame, ch);
                sample /= voice.Buffer.Channels;
            }

            result.SetSample(destFrame, 0, result.GetSample(destFrame, 0) + sample * leftGain);
            result.SetSample(destFrame, 1, result.GetSample(destFrame, 1) + sample * rightGain);
        }
    }
    ```

    This replaces the current buggy code that ignores `voice.Pan` and just duplicates mono to both channels with `voice.Gain` only.
