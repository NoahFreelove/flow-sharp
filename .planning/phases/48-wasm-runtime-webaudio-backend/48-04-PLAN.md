## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Composer source string → C# Execute | source string flows from JS into Flow parser; SECURITY-WISE: Flow has no FFI/filesystem/network access (sandbox by language design — interpreter has no syscalls exposed to user code) — script injection cannot escape the runtime |
| stdout/stderr capture → JS-side RunResult | captured streams are bounded by the 30s wall-clock cap; cannot grow unbounded |
| [JSExport] return value crossing boundary | only JSON-serializable types (string, primitives, byte[], float[]); no .NET object handles leak to JS |
