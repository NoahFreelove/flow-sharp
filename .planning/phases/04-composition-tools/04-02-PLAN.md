    2. Get time signature from first bar of each sequence: `seq.Bars[0].TimeSignature`

       - For each sequence: render via `SequenceRenderer.RenderSequenceToVoices()`, then loop the output to fill the total duration
       - Looping: if the rendered voice data is shorter than total samples, repeat it (copy samples cyclically)

    **Variation implementation (per D-13):**

    Core method: `ApplyVariation(SequenceData seq, double probability, string? mutationType, Random rng, string? keyContext)`:
    - Iterate all bars in the sequence (per D-18, create NEW BarData instances, don't mutate)
    - For each note: if `rng.NextDouble() < probability`, apply mutation
    - If `mutationType` is null (per D-15): randomly pick one of "pitch", "rhythm", "rest", "velocity"
    - If `mutationType` is specified (per D-15): apply only that type

    **Four mutation types (per D-13):**

    1. **"pitch"** (per D-17): Shift by 1-2 scale degrees within active key when key is provided.
       - **Diatonic path (primary, per D-17):** When `keyContext` is not null, call `ScaleDatabase.GetScaleNotes(keyContext)` to get the scale note names (e.g., ["C", "D", "E", "F", "G", "A", "B"] for Cmajor). Find the current note's position in the scale by matching NoteName. Shift by `rng.Next(-2, 3)` scale degrees (wrapping around the scale array, adjusting octave when wrapping). This ensures mutations stay diatonic. For example, in Cmajor: E shifted up 2 degrees becomes G (not F# or G#).
       - **Chromatic fallback:** When `keyContext` is null, use chromatic movement: shift by `rng.Next(-2, 3)` semitones using MIDI arithmetic (ToMidi/FromMidi pattern from TransformFunctions).
       - Clamp resulting MIDI pitch to range 36-96 (C2-C7).

    2. **"rhythm"**: Split a note into two notes of half duration.
       - Only split if DurationValue allows halving (whole->half=2, half->quarter=4, quarter->eighth=8, eighth->sixteenth=16).
       - The two resulting notes both have the same pitch as the original.
       - Preserve bar total duration (per Pitfall 3 from research).
       - Do NOT merge notes (too complex for v1, splitting only is simpler and avoids duration errors).

    3. **"rest"**: Replace the note with a rest of the same duration.
       - Create `new MusicalNoteData(' ', 0, 0, note.DurationValue, isRest: true, isDotted: note.IsDotted)`

    4. **"velocity"**: Adjust velocity by `rng.NextDouble() * 0.4 - 0.2` (range -0.2 to +0.2).
       - Clamp to [0.05, 1.0].
       - Create new MusicalNoteData with modified velocity.

    **Overload routing:**
    - `VaryRandom`: calls `ApplyVariation(seq, prob, null, new Random(), null)` -- random mutation type, chromatic pitch
    - `VaryTyped`: calls `ApplyVariation(seq, prob, type, new Random(), null)` -- specific type, chromatic pitch
    - `VarySeeded`: calls `ApplyVariation(seq, prob, null, new Random(seed), null)` -- random type, seeded, chromatic
    - `VaryTypedSeeded`: calls `ApplyVariation(seq, prob, type, new Random(seed), null)` -- specific type, seeded, chromatic
    - `VaryTypedWithKey`: calls `ApplyVariation(seq, prob, type, new Random(), key)` -- specific type, diatonic pitch (per D-17)
    - `VaryTypedWithKeySeed`: calls `ApplyVariation(seq, prob, type, new Random(seed), key)` -- specific type, seeded, diatonic
