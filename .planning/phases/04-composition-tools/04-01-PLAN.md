    ```csharp
    namespace FlowLang.Runtime;

    public class ProgressionCompiler
    {
        public SequenceData Compile(ProgressionExpression expr, MusicalContext context)
        {
            // 1. Validate key context exists (per D-03)
            if (context.Key == null)
                throw new InvalidOperationException(
                    "progression requires an active key context (use `key Cmajor { ... }`)");

            // 2. Get time signature (default 4/4)
            var timeSig = context.TimeSignature ?? new TimeSignatureData(4, 4);

            // 3. Resolve all roman numerals to ChordData (per D-03)
            var chords = new List<(ChordData chord, int barCount)>();
            foreach (var elem in expr.Chords)
            {
                var chordData = ScaleDatabase.ResolveRomanNumeral(elem.Numeral, context.Key);
                if (chordData == null)
                    throw new InvalidOperationException(
                        $"Cannot resolve '{elem.Numeral}' in key {context.Key}");
                chords.Add((chordData, elem.BarCount));
            }

            // 4. Determine voice count (per D-05)
            int voiceCount = expr.VoiceCount ?? chords.Max(c => c.chord.NoteNames.Length);

            // 5. Voice leading (per D-06, D-07)
            var sequence = new SequenceData();
            int[] currentPitches = InitializeVoices(chords[0].chord, voiceCount);

            for (int i = 0; i < chords.Count; i++)
            {
                var (chord, barCount) = chords[i];
                if (i > 0) // First chord already initialized (per D-07)
                    currentPitches = ApplyVoiceLeading(currentPitches, chord, voiceCount);

                for (int b = 0; b < barCount; b++)
                {
                    var bar = BuildBar(currentPitches, timeSig);
                    sequence.AddBar(bar);
                }
            }

            return sequence;
        }
    }
    ```

    **Voice leading implementation details (per D-06):**

    `InitializeVoices(ChordData chord, int voiceCount)`:
    - Get chord note names from `chord.NoteNames`
    - Bass voice: chord root at octave 3 (MIDI ~48 for C)
    - Upper voices: spread chord tones in octave 4 (MIDI ~60-72)
    - If voiceCount > chord notes: double the root or fifth
    - If voiceCount < chord notes: drop extensions (keep root, third, fifth)
    - Use `ToMidi`-style conversion: map note name (C, D, E...) + octave to MIDI number
    - Implement ToMidi/FromMidi locally in ProgressionCompiler (same logic as TransformFunctions but made internal/public since those are private)

    `ApplyVoiceLeading(int[] prevPitches, ChordData chord, int voiceCount)` (per D-06):
    - Bass (index 0): find nearest chord root in octave 2-3 range to previous bass pitch
    - Upper voices (index 1+): for each voice, find the nearest chord tone (any octave instance within range 48-84 / C3-C6) to its previous pitch
    - Use greedy assignment: process voices in order, mark used target pitches to avoid unison
    - Constrain: bass range MIDI 36-55, upper voices MIDI 48-84 (per Pitfall 1 from research)
    - If voiceCount > chord note count: duplicate root or fifth (per Pitfall 6)

    `BuildBar(int[] pitches, TimeSignatureData timeSig)`:
    - Create a `BarData` with `BarMode.Musical`
    - For each pitch in the array, create a `MusicalNoteData`:
      - Convert MIDI pitch back to (NoteName, Octave, Alteration) via FromMidi
      - Duration: whole note (NoteValueType.Value = 1) for 4/4 time, or adjust to fill one bar based on time signature numerator
      - Velocity: 0.63 (default)
    - All notes sound simultaneously (same offset in bar) -- this means each voice is a separate note at the same position. The bar will contain `voiceCount` notes, all with the same duration (filling one bar).
    - Set `bar.TimeSignature = timeSig` and `bar.Mode = BarMode.Musical`
