  <action>
    Per FIX-04: Wrap background engine creation in try/finally to guarantee static manager restoration.

    In LiveReloadManager.cs, find the RenderScript method (around line 344-374). Currently the code is:
    ```csharp
    var savedManager = PlaybackFunctions.GetManager();
    using var engine = new FlowEngine();
    engine.AudioManager.CaptureMode = true;
    engine.Execute(source, filePath);
    if (savedManager != null)
        PlaybackFunctions.SetManager(savedManager);
    // ... rest of buffer extraction
    ```

    Restructure to:
    ```csharp
    var savedManager = PlaybackFunctions.GetManager();
    try
    {
        using var engine = new FlowEngine();
        engine.AudioManager.CaptureMode = true;
        engine.Execute(source, filePath);

        // Extract musical context from the execution
        musicalContext = engine.Context.GetMusicalContext();

        // Try to get captured buffer
        var buffer = engine.AudioManager.GetCapturedBuffer();

        if (buffer == null)
        {
            var result = engine.ExecuteExpression(source, filePath);
            if (result?.Data is AudioBuffer audioBuf)
            {
                buffer = audioBuf;
            }
        }

        return buffer;
    }
    finally
    {
        // Always restore, even if savedManager is null (first engine creation)
        // and even if Execute() throws an exception
        PlaybackFunctions.SetManager(savedManager!);
    }
    ```

    Key changes:
    1. Wrap everything from `using var engine` through `return buffer` in try block
    2. Move restore to finally block (guarantees execution on throw)
    3. Remove the `if (savedManager != null)` guard -- use null-forgiving operator since SetManager should handle the restore unconditionally
    4. Verify that PlaybackFunctions.SetManager accepts the value (check if it needs a null guard internally -- if SetManager throws on null, keep the null check but in the finally block)
  </action>
