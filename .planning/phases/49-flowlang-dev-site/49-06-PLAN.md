<!-- URL-fragment share (RESEARCH Pattern 7, D-49-30): -->
  import { deflateSync, inflateSync, strToU8, strFromU8 } from 'fflate';
  encode(src) = base64url(deflateSync(strToU8(src)))    // replace +/ → -_, strip =
  decode(frag) = strFromU8(inflateSync(base64urlDecode(frag)))
  Fragment `#code=...` never leaves the browser. base64url avoids +//= URL issues.
  DEFENSIVE (Security V5): wrap inflate in try/catch → UI-SPEC "Couldn't decode this shared snippet";
  CAP decoded size BEFORE loading into the editor (decompression-bomb guard).

<!-- Gist OAuth (RESEARCH Pattern 6, Willison TIL, D-49-28/29; Security V2): -->
  1. Browser → github.com/login/oauth/authorize?client_id=...&redirect_uri=.../api/auth/github
       &scope=gist&state=<crypto.getRandomValues> (state stashed in a cookie)
  2. Callback → worker POSTs github.com/login/oauth/access_token {client_id, client_secret, code, state}
       (Accept: application/json). Worker VALIDATES state (CSRF) against the cookie BEFORE exchange.
  3. Worker redirects ONLY to same-origin /playground with the token in the URL fragment → sessionStorage.
  4. Gist creation client-side: POST api.github.com/gists with Authorization: Bearer <token> (D-49-29).
  Worker route: /api/auth/github. ≤50 LOC. GITHUB_CLIENT_SECRET = CF env (NEVER client bundle).
  scope=gist ONLY (least privilege). Open-redirect guard: never reflect a user-supplied redirect param.

UI (UI-SPEC §Playground left rail + §Copywriting): "Share" (secondary) copies the link →
  "Link copied — anyone can open this snippet"; "Save to gist" (brass primary) → OAuth →

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `/api/auth/github` (CF Worker) | OAuth code crosses here; the worker holds `client_secret` |
| `#code=` fragment → editor | Attacker-controllable compressed source decoded client-side |
| client → api.github.com | Gist POST with the user's token (Bearer) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-OAUTH-CSRF | Spoofing | OAuth callback | mitigate | `state` = `crypto.getRandomValues`, stashed in an httpOnly cookie, validated server-side BEFORE the code exchange; mismatch → 400, no exchange (Pattern 6, unit-tested) |
| T-49-SECRET | Information Disclosure | client_secret | mitigate | `GITHUB_CLIENT_SECRET` only in the CF Worker env; never in the client bundle; build-output scan asserts its absence (D-49-28) |
| T-49-REDIRECT | Tampering | OAuth redirect | mitigate | Redirect hard-coded to same-origin `/playground`; no user-supplied redirect param is ever reflected (open-redirect guard) |
| T-49-CSP-FRAG | DoS / Tampering | `#code=` decode | mitigate | Defensive inflate (try/catch → friendly error) + decoded-size cap before allocation (decompression-bomb guard); rendered as text, never `{@html}` (Security V5) |
| T-49-SCOPE | Elevation | gist token scope | mitigate | OAuth requests `scope=gist` only (least privilege); token in sessionStorage (ephemeral, D-49-28) |
| T-49-XSS-SHARE | Tampering | shared source render | mitigate | Shared source loads into Monaco as text, never innerHTML; console renders escaped (Plan 49-05 carryforward) |
</threat_model>
