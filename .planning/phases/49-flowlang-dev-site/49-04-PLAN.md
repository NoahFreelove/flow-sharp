## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build container → wiki repo | `git clone` pulls markdown; rendered to static HTML at build time (no runtime fetch) |
| rendered docs → browser | Wiki markdown → escaped HTML; no user-supplied input on docs routes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-04-XSS | Tampering | mdsvex/shiki render | mitigate | shiki emits escaped HTML; docs content is first-party wiki (not user input); never `{@html}` raw untrusted source (UI-SPEC §error box rule applies site-wide) |
| T-49-04-SYNC | Denial of Service | sync-wiki.sh | mitigate | `set -euo pipefail` fails the build loudly (no empty-docs ship); in-repo seed fallback guarantees a build never blocks on a transient clone failure |
| T-49-04-RE | Tampering | [[link]] regex | mitigate | Fenced-code-block-aware split prevents the regex from corrupting array literals (Pitfall 7); idempotency unit-tested |
</threat_model>
