# Phase 49 — UI Design Contract

> Visual and interaction contract for the flowlang.dev marketing + docs + WASM playground + showcase site.
> **Locked visual direction: SKEUOMORPHIC** (D-49-06, composer-locked 2026-05-25) — Logic Pro wood-panel racks, Reason rack views, GarageBand instrument editors, vintage synth hardware (Moog Model D, ARP Odyssey, Sequential Prophet-5). Tactile music-software tradition, NOT generic AI-template glassmorphism.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker. Consumed by gsd-planner + executor as the visual source of truth.

## Design System

| Property | Value |
|----------|-------|
| Tool | **none** (no shadcn — stack is SvelteKit/Svelte, not React) |
| Preset | not applicable |
| Component library | **manual** — custom skeuomorphic component library at `flow-site/src/lib/components/skeuo/` (D-49-19) |
| Styling | Tailwind CSS v4 (CSS-first `@theme`, no `tailwind.config.js`) + custom CSS for skeuo materials/textures; tokens at `flow-site/src/lib/design/tokens.css` (D-49-17) |
| Icon library | **Lucide** (`lucide-svelte`) for UI affordance icons (outbound arrow, copy, download, theme toggle, GitHub mark). DEFAULT choice — clean line icons that read on both metal and paper surfaces; no neon/filled "AI starter" iconography. Skeuo controls (Knob/LedIndicator) are CSS/SVG-drawn, NOT icon-font glyphs. |
| Body font | **Inter** (variable) — humanist sans, body + UI. DEFAULT chosen from D-49-06's Inter/Plus Jakarta pair (Inter has the widest weight range + best small-size rendering for status bars). |

DEFAULT chosen from D-49-06's Cooper Black/Recoleta/Krona set — Recoleta's warm hand-set serif matches the warm-walnut palette without Cooper Black's heaviness at body-adjacent sizes. Self-hosted (no Google Fonts CDN, keeps CSP tight). |
| Code font | **JetBrains Mono** — all code blocks, Monaco editor, status bar metrics (D-49-06; conventional for music software displays). |

**Font loading:** self-host all three as `woff2` under `static/fonts/`, `font-display: swap`, preload the above-fold Recoleta wordmark + Inter regular. No Google Fonts CDN (CSP `font-src 'self'` per D-49-38).

## Spacing Scale

Declared values (D-49-17 — multiples of 4; 12 is the one allowed mid-step because it is a multiple of 4):

| Token | CSS var | Value | Usage |
|-------|---------|-------|-------|
| 4xs | `--space-1` | 4px | Icon gaps, hairline insets, LED-to-label gap |
| 3xs | `--space-2` | 8px | Compact control padding, knob-to-caption gap |
| 2xs | `--space-3` | 12px | Button internal padding, panel-edge inset |
| xs | `--space-4` | 16px | Default element spacing, card padding |
| sm | `--space-6` | 24px | Panel padding, docs paragraph rhythm |
| md | `--space-8` | 32px | Layout gaps, section inner padding |
| lg | `--space-12` | 48px | Major section breaks (Home sections) |
| xl | `--space-16` | 64px | Page-level vertical rhythm, hero top/bottom |

Exceptions:
- Skeuo interactive touch targets meet a **44px minimum hit area** (knobs, buttons, toggles, tab targets) even when the visual cap is smaller — pad the hit region, not the visual. This is the only deliberate departure from the pure 4-step scale and exists for pointer + touch a11y (D-49-09 mobile).
- Brushed-metal nav bar height fixed at **56px** desktop / **48px** mobile (one component-specific value, not a general token).

Type scale D-49-17 (12/14/16/18/24/32/48) mapped to roles. Each pairs an exact line-height and letter-spacing.

Weights in use (deliberately restrained):
- **Inter:** 400 (regular) + 600 (semibold). No light, no black.
- **Recoleta:** 700 (the single display weight). Wordmark + hero only.
- **JetBrains Mono:** 400.

Wordmark treatment: `Recoleta 700`, letter-spacing `-0.03em`, color walnut (light) / cream (dark). Optional 1px top inner-bevel highlight (`text-shadow: 0 1px 0 rgba(255,255,255,0.4)` light theme) to read as embossed on the brushed-metal nav — NOT a gradient fill. Reduced-motion + reduced-transparency users keep the flat colored wordmark.

## Color

Skeuo-adapted 60/30/10 split. **Paper is the 60% dominant surface; wood/walnut is the 30% structural secondary; brass is the reserved 10% accent.** Slate is the code-surface neutral. Dark mode is a SECOND skeuo theme (D-49-20), not an inversion.

### Light theme (default — paper + walnut + brass)

| Role | CSS var | Value | Usage |
|------|---------|-------|-------|
| Dominant (60%) | `--color-paper` | `#F5F0E6` | Page background, doc page bodies, card faces, console surface |
| Secondary (30%) | `--color-walnut` | `#5C3A21` | Wood side rails, panel frames, editor borders, footer, structural chrome |
| Secondary alt | `--color-walnut-soft` | `#7A5235` | Wood-grain highlight band, panel bevel light edge |
| Accent (10%) | `--color-brass` | `#C9A567` | **RESERVED — see list below** |
| Neutral (code) | `--color-slate` | `#2C2E33` | Code-block background, Monaco editor chrome, status bar |
| Ink (text) | `--color-ink` | `#241A12` | Body text on paper (paper #F5F0E6 → contrast 12.8:1, passes AAA) |
| Ink-muted | `--color-ink-muted` | `#5A4B3C` | Captions, secondary text on paper (contrast 6.1:1, passes AA) |
| Felt | `--color-felt` | `#6E2B2B` | Grille fabric behind "playing" LED indicators (decorative, never text) |
| Destructive | `--color-danger` | `#A8322B` | "Stop" affordance accent, error-box rail, destructive confirms only |

### Dark theme (`[data-theme="dark"]` — deep walnut + amber-LED accents)

| Role | CSS var | Value | Usage |
|------|---------|-------|-------|
| Dominant (60%) | `--color-paper` | `#2A1F18` (deep walnut) | Page background, panel faces in low-light "studio" mode |
| Secondary (30%) | `--color-walnut` | `#1C140E` | Darker structural chrome, rails, frames |
| Secondary alt | `--color-walnut-soft` | `#3A2A1E` | Bevel light edge in dark |
| Accent (10%) | `--color-brass` | `#E0B45C` (amber-LED) | Same reserved list, warmer/brighter to read as glowing amber gear LEDs |
| Neutral (code) | `--color-slate` | `#15161A` | Code background, Monaco chrome |
| Ink (text) | `--color-ink` | `#EDE3D3` (soft cream) | Body text on deep walnut (contrast 11.4:1, passes AAA) |
| Ink-muted | `--color-ink-muted` | `#B8A78F` | Captions (contrast 6.3:1, passes AA) |
| Felt | `--color-felt` | `#4A1E1E` | Grille fabric, darker |
| Destructive | `--color-danger` | `#E0635A` | Stop / error rail, brightened for dark contrast |

### Accent reserved for (the explicit 10% list — brass/amber appears ONLY here)

1. **Primary CTA fills** — "Play in playground", "Run", "Open in playground", "Save to gist" buttons (the single highest-intent action per surface). Secondary buttons stay metal/wood, NOT brass.
2. **Focus ring** — brass-colored 2px `:focus-visible` outline on every interactive skeuo element (D-49-10). 2px solid + 1px offset; visible on metal, wood, AND paper.
3. **Active-tab indicator** — the brass underline/inset on the current top-nav tab (one tab brass at a time).
4. **LedIndicator "playing" glow** — the amber pinpoint glow on `<LedIndicator>` while audio is rendering/playing (the skeuo replacement for a generic "loading" spinner color).
5. **Active control knob pointer + value arc** — the brass tick on a `<Knob>` and its swept value arc (the "current value" indicator).

Brass is NEVER used for: body text, large background fills, card faces, plain links (links are walnut underline), borders that aren't a focus ring, or hover states of non-primary controls. If brass appears on more than ~10% of any viewport, it is wrong.

### Contrast pairs (all meet WCAG AA, D-49-10 4.5:1 body / 3:1 large)

| Pair | Ratio | Verdict |
|------|-------|---------|
| Ink `#241A12` on paper `#F5F0E6` (light body) | 12.8:1 | AAA |
| Ink-muted `#5A4B3C` on paper (light caption) | 6.1:1 | AA |
| Cream `#EDE3D3` on deep walnut `#2A1F18` (dark body) | 11.4:1 | AAA |
| Walnut `#5C3A21` text on brass `#C9A567` (button label on brass CTA) | 4.6:1 | AA (large+normal OK) |
| Slate `#2C2E33` code-surface text uses light syntax tokens at ≥ 4.5:1 (shiki `github-light`/`github-dark` themes, D-49-15) | — | verified by theme |
| Brass `#C9A567` focus ring on paper | 1.9:1 (decorative ring, not text) | exempt; ring also carries 1px walnut inner edge for non-color affordance |

CTA labels render in **walnut on brass** (light) / **deep-walnut on amber** (dark) — dark text on the warm accent, never white-on-brass (fails contrast).

## Material Surfaces (D-49-18)

Four `.surface-*` utility classes layered on Tailwind. Texture authoring approach noted per D-49-18/32. DEFAULT authoring decisions chosen below (within Claude's discretion per CONTEXT §"Claude's Discretion").

| Class | Built from | Where used | Reduced-data / fallback |
|-------|-----------|------------|--------------------------|
| `.surface-brushed-metal` | CSS linear-gradient base (`--color-slate` → lighter satin band) + **inline SVG anisotropic-noise `<feTurbulence>` overlay** (horizontal brush direction, low opacity) — no raster. | Top nav / header bar; button faces (`<Button>` default); status bar strip; `<MetalRail>`. | Solid satin gradient if SVG filter unsupported. |
| `.surface-wood` | Walnut base gradient + **raster wood-grain texture** (the one case SVG can't capture per D-49-18) served AVIF/WebP/PNG via Sharp (D-49-32, ≥80% AVIF). Tiled vertically for rails. | Side rails (playground left col, docs sidebar frame); editor borders; `<Panel>` frame; footer band. | Walnut flat gradient (`--color-walnut` → `--color-walnut-soft`) if texture image fails. |
| `.surface-paper` | Cream base (`--color-paper`) + **inline SVG paper-fiber `<feTurbulence>` speckle** at very low opacity + optional faint staff-line ruling (5-line SVG pattern) on docs backgrounds only. | Doc page bodies (`/docs/[slug]`); card faces; console output surface; hero paper inlay. | Flat cream `--color-paper`. |
| `.surface-felt` | **Inline SVG dot/weave pattern** overlay over `--color-felt`, with subtle inner shadow (recessed grille). | Behind "playing" `<LedIndicator>` grilles; showcase audio-player speaker-grille motif. | Flat felt color. Decorative only — never sits behind text. |

Texture rules:
- Inline-SVG patterns preferred (smaller, scalable, inlinable in critical CSS per D-49-33). Raster only for wood grain.
- All raster textures: AVIF + WebP + PNG fallback, Sharp build step, never below 80% AVIF (D-49-32). Skeuo look depends on textures reading right.
- Texture overlays are **deferred / non-critical CSS** (D-49-33) — the base gradient ships in critical CSS so first paint is correct before the overlay loads.
- `prefers-reduced-data` (and texture-load failure): every surface degrades to its flat base color/gradient and stays legible.

## Component Inventory (D-49-19 — ≤8 base components)

Each component: purpose · variants · states (default / hover / active-pressed-inset / focus-brass-ring / disabled) · reduced-motion fallback · a11y contract. Restraint is mandatory — overuse of skeuo becomes parody (D-49-19).

### 1. `<Button>` — embossed satin-metal action

- **Purpose:** all clickable actions (CTAs, secondary actions, icon buttons).
- **Variants:** `primary` (brass face, walnut label — the reserved-accent CTA), `secondary` (brushed-metal face, ink label), `ghost` (no face, ink label — for low-emphasis nav-adjacent actions), `icon` (square, 44px hit, single Lucide glyph), `danger` (uses `--color-danger` rail — Stop / destructive only).
- **States:**
  - default: embossed — light bevel top edge, 1–3px drop shadow bottom edge (D-49-06), `.surface-brushed-metal` or brass.
  - hover: bevel brightens ~6%; shadow unchanged (no lift/translate that implies a different material).
  - **active/pressed: INSET** — invert bevel (shadow moves to top inner edge), translate label 1px down, depress over **50ms** (D-49-06).
  - focus: **brass 2px `:focus-visible` ring** + 1px offset (D-49-10), independent of hover.
  - disabled: desaturate face ~40%, remove bevel + shadow (flat), `cursor: not-allowed`, `aria-disabled="true"`.
- **Reduced-motion:** no 50ms travel; pressed state is an instant bevel-swap (D-49-10 "buttons lose travel"). Shadows still present (only motion removed; flat-appearance rule applies to motion, not to depth here — see Motion section for the cards-lose-shadows nuance).
- **A11y:** real `<button>`; `aria-label` on icon-only; label text ≥14px; 44px min hit; brass label/face pair ≥4.5:1.

### 2. `<Knob>` — rotary control (a11y-critical)

- **Purpose:** "more is better" continuous controls (e.g. playground output volume if a volume control ships; any future tempo/gain affordance). Use sparingly — D-49-06 "only when it makes sense — don't force."
- **Variants:** `default` (notched brass pointer), `large` (hero/feature). One size token set; no decorative-only knobs.
- **States:**
  - default: circular metal cap, brass pointer tick at current angle, swept brass value-arc, caption row below = parameter label + current value.
  - hover: pointer-cursor; subtle cap-highlight.
  - active (dragging): pointer follows pointer-drag with **rotational damping** (physical-feeling easing); cap shows inset press.
  - focus: brass 2px ring around the knob bounding box.
  - disabled: greyed cap, no pointer interaction, `aria-disabled`.
- **Reduced-motion:** **render as a flat horizontal `<Slider>`/`role=slider` track instead of a rotating cap** (D-49-10 "knobs become flat sliders"). Same value, same keyboard model, no rotation animation.
- **A11y contract (MANDATORY, per RESEARCH WAI-ARIA + D-49-10):**
  - `role="slider"`, `tabindex="0"`, focusable.
  - `aria-label={parameter name}`, `aria-valuemin`, `aria-valuemax`, `aria-valuenow`, **`aria-valuetext="{value} {unit}"`** (knob labeled with parameter + current value — D-49-10).
  - Keyboard: ArrowUp/ArrowRight → +step; ArrowDown/ArrowLeft → −step; Home → min; End → max; PageUp/PageDown → ±large step.
  - Visible value read-out caption next to every knob (not just the SR text).

### 3. `<Toggle>` — pill switch with sliding knob

- **Purpose:** binary state (theme light/dark toggle in nav; any on/off such as stdout/stderr filter, MIDI-export-on).
- **Variants:** `default`, `with-icons` (sun/moon for the theme toggle).
- **States:**
  - off: knob seated left, recessed track (inset shadow), neutral metal knob.
  - on: knob slides right with **cubic-bezier(0.16,1,0.3,1)** overshoot-correct ease (D-49-06); track tints toward brass-adjacent (subtle, not full brass — accent budget).
  - hover: knob cap brightens.
  - active: knob compresses slightly (inset).
  - focus: brass 2px ring on the pill.
  - disabled: flat track, no slide, `aria-disabled`.
- **Reduced-motion:** knob snaps between positions instantly (no slide).
- **A11y:** `role="switch"`, `aria-checked`, `aria-label` (e.g. "Dark mode"); operable with Space/Enter; theme choice persists in `localStorage` (D-49-20).

### 4. `<Panel>` — wood-framed container

- **Purpose:** the framed container that wraps editor/console/showcase content — the "rack module" frame.
- **Variants:** `framed` (full `.surface-wood` border + corner screws motif), `inset` (recessed content well), `header` (panel with a brushed-metal title strip).
- **States:** mostly static; optional `elevated` (8–16px secondary shadow for floating panels per D-49-06) vs `seated` (1–3px). No hover/press (it's a container) unless used as a clickable card → then borrow `<Button>` press semantics.
- **Reduced-motion:** none needed (static), but **cards/panels lose their drop shadows under `prefers-reduced-motion` per D-49-10** — flatten `elevated`/`seated` to a 1px walnut border so depth cue is preserved without the shadow.
- **A11y:** when a Panel is a landmark region (e.g. console = `aside`), it carries the role + `aria-label`. Decorative screw/grain elements are `aria-hidden`.

### 5. `<MetalRail>` — brushed-aluminum side decoration

- **Purpose:** vertical brushed-metal trim flanking panels/rails (the rack-rail motif). Purely decorative structure.
- **Variants:** `left`, `right` (brush-direction/light source mirrored).
- **States:** static. No interaction.
- **Reduced-motion:** none.
- **A11y:** `aria-hidden="true"` — decorative; never contains content or focus targets.

### 6. `<LedIndicator>` — amber pinpoint "playing" glow

- **Purpose:** the skeuo status light. Replaces generic spinners. States: idle (dark), rendering (amber pulse), playing (steady amber glow), error (red).
- **Variants:** `playing`, `rendering`, `idle`, `error`.
- **States / behavior:**
  - idle: unlit dark lens on `.surface-felt` grille.
  - rendering: amber **pulse** (opacity breathe) while `run()` is in flight.
  - playing: steady amber glow while AudioContext is `running`.
  - error: red lens (uses `--color-danger`).
- **Reduced-motion:** pulse → steady on/off (no breathing animation).
- **A11y:** **status conveyed by text + ARIA, not color alone** — paired with a visually-hidden `aria-live="polite"` text ("Rendering…", "Playing", "Stopped", "Error"). LED itself `aria-hidden`; the live-region text is the SR truth.

### 7. `<Slider>` — channel-strip fader

- **Purpose:** linear value control (volume fader if a volume control ships; also the reduced-motion fallback target for `<Knob>`).
- **Variants:** `vertical` (channel-strip fader), `horizontal` (inline / knob-fallback).
- **States:**
  - default: recessed track (inset), metal fader cap, brass fill below the cap.
  - hover: cap highlight.
  - active (dragging): cap inset; brass fill follows.
  - focus: brass 2px ring.
  - disabled: flat track, greyed cap.
- **Reduced-motion:** no fill-animation tween; value jumps instantly.
- **A11y:** native `<input type="range">` styled, OR `role="slider"` with the same `aria-valuemin/max/now/valuetext` + arrow-key contract as `<Knob>`. Labeled with parameter + current value.

### 8. `<Tabs>` (top-nav) — embossed segmented rack selector

> The 8th component slot. The five-tab nav (Home / Docs / Playground / Showcase / GitHub) is a distinct interaction surface and earns a component; it is the "Panel-framed container" 8th entry implied by D-49-19.

- **Purpose:** the 5-tab top-level navigation on `.surface-brushed-metal`.
- **Variants:** `local` (4 router tabs), `external` (GitHub — `target="_blank"` + Lucide outbound-arrow glyph + `rel="noopener noreferrer"`).
- **States:**
  - default: flat embossed metal tab label.
  - hover: bevel brighten.
  - active/current: **brass inset underline indicator** (the reserved-accent active-tab cue) + label weight 600.
  - focus: brass 2px ring on the focused tab.
- **Reduced-motion:** active-tab indicator snaps (no slide between tabs).
- **A11y:** `<nav aria-label="Primary">`; tabs are real `<a>` links (router) with `aria-current="page"` on the active route; external GitHub link announces "(opens in new tab)" via visually-hidden text; tab order matches left-to-right visual order.

**Component count = 8 base** (Button, Knob, Toggle, Panel, MetalRail, LedIndicator, Slider, Tabs). Meets the ≤8 ceiling exactly.

### Playground error box (renders Phase 48 `RunResult.errors[]`, D-48-14)

A Rust-style diagnostic box per error, on `.surface-paper` with a `--color-danger` left rail:

```
✕ {kind}: {message}
  ┌─ line {line}:{column}
  │ {sourceSnippet}
  │            ^^^^ here
```

- `kind ∈ parse | eval | runtime | platform-not-supported` (the `cancel` kind is defined but not raised in-browser per D-48-10 — handle gracefully if present, but don't surface a confusing "cancelled" to composers).
- `line`/`column`/`sourceSnippet` are optional — render the caret row only when present; fall back to just `{kind}: {message}` otherwise.
- Errors render as **escaped text** (never `{@html}`) — the source is attacker-controllable via `#code=` (Security Domain V5).
- stderr advisories (`[tuning] …`, `[live] …`, Phase 48 D-48-15) are NOT errors — render them in the muted stderr sub-region of the console, not the red diagnostic box.

## Motion + Reduced-Motion (D-49-06, D-49-10)

| Motion | Curve / duration | CSS var |
|--------|------------------|---------|
| Button depress | translate label 1px, **50ms** | `--motion-press: 50ms` |
| Toggle / tab slide, panel transitions | **cubic-bezier(0.16, 1, 0.3, 1)** (overshoot-correct), 180ms | `--ease-overshoot`, `--motion-slide: 180ms` |
| Knob rotation (drag) | rotational easing with damping (physical feel), follows pointer | `--ease-knob` (damped) |
| LED pulse (rendering) | opacity breathe, 1.2s loop | `--motion-led: 1200ms` |
| Hover bevel brighten | 120ms ease-out | `--motion-hover: 120ms` |

`prefers-reduced-motion: reduce` flattening rules (D-49-10), applied globally + per-component:

- All transitions/animations → instant (`animation-duration: 0.001ms; transition-duration: 0.001ms` per RESEARCH code example).
- **Knobs → flat sliders** (render the `<Slider>` fallback, no rotation).
- **Buttons lose travel** (instant bevel-swap, no 50ms depress).
- **Cards/panels lose drop shadows** → replaced with a 1px walnut border so the depth/grouping cue survives without shadow (D-49-10).
- LED pulse → steady on/off.
- The flat-appearance + correct color/contrast must be fully preserved (no information lost when motion is removed).

## Accessibility Contract (D-49-10, D-49-31 — Lighthouse Accessibility ≥90)

- **Keyboard navigation:** every interactive element reachable via Tab; **tab order matches visual reading order** (left-to-right, top-to-bottom). Knobs/sliders operable with arrow keys (full contract in component inventory). No keyboard traps. Visible focus on all.
- **Focus ring:** brass-colored **2px `:focus-visible` outline + 1px offset** on every skeuo interactive element (D-49-10). Carries a 1px walnut inner edge so it reads against brass surfaces (non-color-dependent). Never removed for aesthetics.
- **ARIA landmarks:** `<nav aria-label="Primary">`, `<main>`, `<aside aria-label="…">` (playground rails, docs sidebar), `<footer>`. One `<main>` per page.
- **Screen-reader labels:** every interactive element labeled. Icon-only buttons carry `aria-label`. **Knobs/sliders labeled with parameter + current value** (`aria-label` + `aria-valuetext`). External GitHub link announces "opens in new tab."
- **Status not by color alone:** `<LedIndicator>` state mirrored in a visually-hidden `aria-live="polite"` region ("Rendering…/Playing/Stopped/Error"). Error diagnostics carry the `kind` as text, not just the red rail.
- **Color contrast:** body ≥ 4.5:1, large text ≥ 3:1 (D-49-10) — pairs verified in the Color section. Both themes pass.
- **Reduced motion:** honored per the Motion section.
- **Images/textures:** decorative textures, screws, grain, rails are `aria-hidden` / empty `alt`. Meaningful icons carry labels.
- **Target size:** 44px minimum hit area on all controls (Spacing exception).
- **Lighthouse Accessibility ≥ 90** on `/`, `/docs`, `/playground` (mobile + desktop), verified Plan 49-08 with `@axe-core/playwright` (0 critical violations) + manual keyboard + VoiceOver/NVDA smoke.
