Per D-01, D-02, D-03: Add `//` line comment handling to `SkipWhitespaceAndComments()` in SimpleLexer.cs.

In the `SkipWhitespaceAndComments()` method, add a new `else if` branch BEFORE the existing `Note:` branch (line ~801). The check:

```csharp
else if (c == '/' && PeekNext() == '/')
{
    // Line comment: skip to end of line
    while (!IsAtEnd() && Peek() != '\n')
    {
        Advance();
    }
}
```

This goes after the line continuation checks (backslash + newline) and before the `Note:` check. Comments are treated as whitespace — completely invisible to the parser, no AST node needed. Only `//` single-line comments, no `/* */` block comments.

IMPORTANT: The `/` single-char token in NextToken (line ~106: `case '/': return SingleChar(TokenType.Slash)`) is fine — `SkipWhitespaceAndComments()` runs first in the Tokenize loop, so `//` is consumed before NextToken ever sees it.

Create `tests/test_comments.flow` with these test cases:
1. `// full line comment` (should be ignored)
2. Code followed by `// inline comment` — e.g., `Int x = 5 // set x`
3. `// comment` before a code line
4. Multiple consecutive `// comment` lines
5. Comment inside a proc body
6. Comment after a note stream expression (e.g., `Sequence s = | C4 D4 | // melody`)
7. Division operator still works: `Int y = (div 10 2)` followed by `// this divides` on same line
8. Use `(print "...")` assertions to verify the code around comments executes correctly

**Step 1: Add RegisterMath method to BuiltInFunctions.cs**

Add a new `private static void RegisterMath(InternalFunctionRegistry registry)` method. Register these functions using the same pattern as RegisterStdLib (FunctionSignature + lambda):

```
sin(Double) -> Double:    Math.Sin(args[0].As<double>())
cos(Double) -> Double:    Math.Cos(args[0].As<double>())
tan(Double) -> Double:    Math.Tan(args[0].As<double>())
abs(Double) -> Double:    Math.Abs(args[0].As<double>())
abs(Int) -> Int:          Math.Abs(args[0].As<int>())
sqrt(Double) -> Double:   Math.Sqrt(args[0].As<double>())
min(Double, Double) -> Double:  Math.Min(args[0].As<double>(), args[1].As<double>())
min(Int, Int) -> Int:     Math.Min(args[0].As<int>(), args[1].As<int>())
max(Double, Double) -> Double:  Math.Max(args[0].As<double>(), args[1].As<double>())
max(Int, Int) -> Int:     Math.Max(args[0].As<int>(), args[1].As<int>())
floor(Double) -> Int:     (int)Math.Floor(args[0].As<double>())
ceil(Double) -> Int:      (int)Math.Ceiling(args[0].As<double>())
round(Double) -> Int:     (int)Math.Round(args[0].As<double>())
pi() -> Double:           Math.PI  (zero-arg function, empty parameter list)
tau() -> Double:          Math.Tau (zero-arg function, empty parameter list)
```
