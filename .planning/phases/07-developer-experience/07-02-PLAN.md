Add a private method:

```csharp
private void AutoImportStandardModules()
{
    var imports = new[]
    {
        "use \"@std\"",
        "use \"@audio\"",
        "use \"@collections\""
    };

    foreach (var import in imports)
    {
        _engine.Execute(import, "<repl-init>");
        // Clear any errors from auto-import (e.g., if audio not available)
        _engine.ErrorReporter.Clear();
    }
}
```

Key details:
- Use `_engine.Execute()` not `ExecuteExpression()` — we don't need the return value
- Clear errors after each import so the user doesn't see startup noise
- The fileName `"<repl-init>"` distinguishes auto-imports from user input in diagnostics
- Script mode (file argument via ScriptRunner/Program.cs) is UNCHANGED — explicit imports required per D-13
- The auto-imports happen once at startup, not per-input
