slice (Sequence and Array) — DX-05 (from tests/test_slice.flow + REQUIREMENTS.md):
```flow
// Array form: start inclusive, end exclusive, silent two-sided clamp
Int[] xs = [10, 20, 30, 40, 50]
Int[] mid = (slice xs 1 4)        // → [20, 30, 40]
Int[] over = (slice xs 3 100)     // → [40, 50]   (end clamped to len)
Int[] empty = (slice xs 3 2)      // → []          (end < start clamps empty)

// Sequence form is bar-level (each '|...|' bar = one slice index)
Sequence threeBars = | C4 D4 | E4 F4 | G4 A4 |
Sequence middleBar = (slice threeBars 1 2)   // → just the second bar
```
slice(Sequence, Int, Int) operates on bars (each `|...|` is a bar; index 0 is first bar). slice(Array[T], Int, Int) operates on elements. Both clamp silently per Phase 14 D-01.

flat literals + enharmonic — DX-06 (from tests/test_flat_literals.flow + tests/test_enharmonic.flow):
```flow
// Flat letters parse as notes inside note streams (Db, Eb, Gb, Ab, Bb, Cb, Fb)
Sequence flats = | Db4 Eb4 Gb4 Ab4 Bb4 |
// Bare flats (no octave digit) default to octave 4
Sequence bare = | Bb Db Eb |
// Sharp via # (already supported pre-v1.2 but parse with the same surface now)
Sequence sharps = | C#4 F#4 G#5 |

// enharmonic(Note) flips sharp ↔ flat. Naturals (C/D/E/F/G/A/B without alteration)
// pass through unchanged per CONTEXT D-05 (DEFER-04 covers E↔Fb / B↔Cb / etc).
(print (str (enharmonic Db4)))    // → C#4
(print (str (enharmonic F#3)))    // → Gb3
(print (str (enharmonic C4)))     // → C4 (natural; unchanged)

// In a key context, enharmonic respells to fit the key. Inside Dbmajor, C# becomes Db.
key Dbmajor {
    (print (str (enharmonic C#4)))    // → Db4
}
```
The enharmonic call returns a Note value; (str ...) converts to "Db4" / "F#3" form.

reverbTime — DX-07 (from tests/test_reverb_time.flow):
```flow
tempo 120 {
    timesig 4/4 {
        // Wraps a Sequence/section in a per-voice RT60 reverb tail.
        reverbTime 2.0 {
            Sequence hallMel = | C4 D4 E4 F4 |
            section hall { hallMel }
            Song hallSong = [hall]
            Buffer wet = (renderSong hallSong "piano")
            (print $"reverbTime 2.0s render: {(str (getFrames wet))} frames")
        }
    }
}
```
- reverbTime takes a Double in seconds. Range 0.0–30.0 (silent clamp at 30s; parse-time error if negative).
- 0.0 is the dry-render sentinel (voice renderer short-circuits Reverb.Apply); per Phase 15 Plan 02. The tutorial chapter MENTIONS this in a comment but the runnable snippet uses a positive value (e.g., 2.0 or 1.5) so the user hears reverb. Stays musically tasteful.
- Stacks with explicit (reverb ...) call — both can be applied.

        // 4-arg form: euclidean(steps, hits, note, swing)
        // 3 hits over 8 steps creates a tresillo rhythm; swing accents on-beats.

        // 6-arg form: euclidean(steps, hits, note, swing, humanize, seed)
