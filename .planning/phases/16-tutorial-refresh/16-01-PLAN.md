mix(Buffer, Buffer) → Buffer (from tests/test_mix.flow):
```flow
Buffer a = (createSineTone 0.5 440.0 0.5)
Buffer b = (createSineTone 0.5 880.0 0.5)
Buffer mixed = (mix a b)        // direct call
Buffer piped = a -> (mix b)      // pipe form
```

gain context block (from tests/test_gain_context.flow) — quiets every section inside:
```flow
gain 0.5 {
  section quiet_part {
    Sequence mel = | C4q E4q G4q C5q |
  }
  Song s = [quiet_part]
  Buffer result = (renderSong s "piano")
}
```
Note: per-section gain (per CONTEXT D-07's "audible integration" requirement) is set by wrapping a `section { ... }` with a `gain N { ... }` context — `result.section.Gain` is what `renderSong` reads. Section-bare-expression form `section foo { (gain ...) }` is NOT how this works; `gain` is a CONTEXT BLOCK around the section.

tempoRamp(Sequence, Double, Double) → Buffer (from tests/test_tempo_ramp.flow):
```flow
Sequence seq = | C4 D4 E4 F4 |
Buffer rit = (tempoRamp seq 120.0 80.0)        // ritardando: slow down
Buffer accel = (tempoRamp seq 80.0 120.0)      // accelerando: speed up
Buffer instr = (tempoRamp seq 120.0 80.0 "piano")  // 4-arg variant with instrument
```
Returns Buffer directly (NOT Sequence). To export a tempoRamp result, use writeWav directly on the Buffer (no renderSong needed).
