```csharp
public void ExecuteStatement(Statement stmt)
{
    if (_returnValue != null)
        return; // Already returned — C2 AUDIT CLAIM: this skips remaining statements after ANY set of _returnValue

    switch (stmt)
    {
        case ProcDeclaration proc:        ExecuteProcDeclaration(proc); break;
        case VariableDeclaration varDecl: ExecuteVariableDeclaration(varDecl); break;
        case AssignmentStatement assn:    ExecuteAssignment(assn); break;
        case ReturnStatement ret:         ExecuteReturn(ret); break;   // <-- legitimate _returnValue setter
        // ... (ImportStatement, SectionDeclaration, MusicalContextStatement, ExpressionStatement, ForStatement, WhileStatement, Break/ContinueSignal throws) ...
    }
}
```

`_returnValue` is a private field on Interpreter. A grep of flow-lang/Interpreter/ for `_returnValue =` will enumerate every assignment; expected legitimate sites are only inside `ExecuteReturn` and `ExecuteProcDeclaration`'s implicit-return collector. Any other assignment is the bug.
</interfaces>
