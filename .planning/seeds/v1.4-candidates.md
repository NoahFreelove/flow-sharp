# v1.4 Candidates

Holding pen for ideas surfaced during v1.3 that are bound for v1.4 (or later).
**Not a roadmap. Not a commitment.** Items here graduate to a v1.4 ROADMAP only
via `/gsd-new-milestone`, which should run *after* `/gsd-complete-milestone v1.3`
produces the v1.3 retrospective and audit.

Until then, this file is a single landing spot so nothing gets lost while v1.3
phases 26 / 26.1 / 27 are still in flight.

## How to add an item

- **Substantial ideas (a phase or more of work):** run `/gsd:capture`,
  create a `SEED-NNN-*.md` in this directory, then add a one-line pointer
  to the **Seed-file candidates** table below.
- **Small ideas (one paragraph or less):** inline under **Inline candidates**.
  Promote to a SEED file when scope grows.
- Always note the **source** (which v1.3 phase or session surfaced it) so
  v1.4 planning can trace context.
