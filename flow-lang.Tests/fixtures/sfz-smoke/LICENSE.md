## Regeneration

```bash
dotnet test flow-lang.Tests/flow-lang.Tests.csproj \
  --filter "Phase33FixtureGenerator_Smoke_GeneratesFixtures"
```

deterministic (no RNG, no time-dependent sample, no platform-dependent
floating-point reduction). Satisfies the Phase 18/25/27 two-run
